# core-message · 找核心

## R — 原文

> “指挥官意图”是位于每道命令最前面的一种表述……“指挥官意图”绝不会悉数阐明诸多琐碎的细节。
> —— 第1章（p40-42）

> 假设你是一位战地记者，电报线路中断前只能发送一则消息，那会是什么呢？只能有一句导语，一个核心。
> —— 第1章（p54）

## I — 自述

核心不是"这段话的摘要"，而是"如果只能保住一句，你保哪句"。

它有三个硬性特征：

1. **能否决**。核心必须能在两个都合理的方案之间做偏向。西南航空的"全球票价最低"可以直接否掉"加免费餐"的提案——这就是合格的核心。"提升客户体验"什么也否不掉。
2. **失效后仍成立**。检验方式是"指挥官意图测试"：如果原计划失败了，这句话还成立吗？"拿下 3 号楼"不成立（楼没了怎么办），"控制东侧通道"成立。
3. **一次只有一个**。五个"最重要"等于没有最重要。强迫排序的痛苦是这项工作的成本，不能绕过——聪明人能从每件事里看出价值，所以更难放弃。

寻找的路径是**倒着走**：先列出所有想要的东西，然后不断问"如果没有它，前面那句还成立吗"，把可替代的一层层剥掉。新闻业把这叫"写导语"——导语不能埋在中后段，必须在最前面出现。

得到的核心通常要再经过一次"谚语化"：不是缩短字数，而是让它在结构上只剩一条主线、且自带节奏便于复述。

## A1 — 书中案例

**卡维尔与"关键是经济啦，笨蛋"**
- 问题：1992 年克林顿竞选团队要同时应付性丑闻、政策细节、媒体每日追问，人人都在忙不同的事。
- 做法：卡维尔在白板上写下三句话给全体助选人员看，其中一句是"关键是经济啦，笨蛋"。"笨蛋"两个字是自我嘲讽，用来提醒团队别耍小聪明。
- 结果：这句话成为整个竞选的核心观点，把分散的注意力收回一条主线上。

**陆军与"指挥官意图"**
- 问题：战场情况变化快于命令传递，士兵常常遇到命令未覆盖的情境。
- 做法：在每道命令最前面加一句意图说明（"我的目标是瓦解东南地区的敌军"／"我的目标是确保那座桥完好"），只讲意图不讲细节。
- 结果：基层在计划失效后仍能自行判断，不必停下来等指令。

**西南航空"全球票价最低的航空公司"**
- 问题：公司每天要面对大量"要不要加这项服务"的提案。
- 做法：把战略压成这一句，作为所有提案的否决依据。
- 结果：免费餐、头等舱、行李转运这类提案一出现就被这句话挡回去，战略得以长期保持一致性。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 材料写完了但"什么都想说"，需要砍到一句。
2. 要写一份立项说明/战略文件/述职报告的开头，不知道第一句写什么。
3. 团队对优先级吵不出结果，每个方向都有人支持。
4. 有一句话（口号/标语/部门定位）想用，但不确定它是不是"能用的"核心——注意：**单句口号/命名的可用性判断归本能力**，不归体检（体检针对整份材料）。

**语言信号**
- 中文：`提炼一个核心` `重点是什么` `一句话说清楚` `太多了砍不下去` `优先级排不出来` `这句话能不能当口号` `slogan 行不行` `标语怎么定` `战略怎么表述` `我的方案没有记忆点` `到底该主打哪一点`
- 英文：`what's the core message` `one-sentence summary` `cut it down to one thing` `what should I lead with` `prioritize` `boil it down`

**与相邻能力的区分（初稿）**
- 与 `stickiness-audit` 的区别：体检是**逐项打分找短板**，本题是**从零选出那一条**。用户说"帮我看看哪里不行"→ 体检；说"帮我定核心"→ 本能力。
- 与 `concretize` 的区别：本能力管"留什么"，具体化管"怎么让它可感知"。核心可以暂时还是抽象的，具体化是下一步。
- 与 `shared-vocabulary` 的区别：本能力产出"一句话"，共同语汇产出"一组能互相搭配的词"。前者给方向，后者给日常判断工具。

## E — 执行步骤

1. **列出全部候选**（完成标准：≥5 条，每条是一个完整句子而不是名词）。
2. **做减法**：逐条问"如果没有它，别的还成立吗"，删掉可被其他条覆盖的。完成标准：剩 1 条。
   - 判停点：若剩 0 条，说明候选之间是并列关系 → 回到步骤 1，改写为"我们宁可牺牲 X 也要保住 Y"的形式再选。
3. **过三关**：
   - 能否决一个具体提案？（举出一个它能否掉的真实提案才算过）
   - 计划失败后还成立吗？（指挥官意图测试）
   - 一个没参与的人能复述吗？
   完成标准：三关全过；任一项不过 → 回到步骤 1 重写，不要修饰措辞。
4. **谚语化**：压到 15 字以内，检查是否保留了一个具体动作或对象。完成标准：读出来有节奏，且删掉任何一个词都会损失信息。
5. **定位**：确认它出现在材料的**最前面**（导语位置），而不是第 3 页。完成标准：前 3 句内出现。

## B — 边界

**不要用**
- 用户只是要一份完整记录/会议纪要/合规文档——这类文本的价值在于不遗漏，找核心会破坏它。
- 材料本身是清单性质的（操作手册、参数表），核心应由使用场景决定而非文本决定。

**书中警告的失败模式**
- 把"简短"当"简单"：删字数不产生核心，只会得到更小的模糊（见 `ce17`）。
- 五个"最重要"并列：等于没有重点，且会让受众陷入决策瘫痪（见 `ce03`）。
- 核心对了但被埋在中后段：这是"埋没导语"，属于结构病（见 `g05`）。

**容易混淆**
- ≠ 摘要（保留多条）／≠ 主题（可抽象到无法否决）／≠ slogan（口号是核心的一种形态，不是定义）。
- 若用户其实想要"让这句话更好记"，那是 `concretize` 或 `curiosity-gap` 的活。

**作者盲点（阶段 0 批判）**
本书假定"只有一个核心"总是更优。但在**探索期**（还没想清楚方向时）过早收敛会锁死选项。若用户明确处于"还在找方向"的阶段，应先用发散方法，而不是逼他收敛——这时要主动说明本能力不适用。

## 相关能力

- 依赖：无（这是链条起点）
- 组合：`concretize`（把核心变成画面）、`shared-vocabulary`（把核心变成组织日常用词）
- 对比：`stickiness-audit`（诊断已有材料 vs 从零选定核心）
