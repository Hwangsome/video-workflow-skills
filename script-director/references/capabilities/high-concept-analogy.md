# high-concept-analogy · 用旧概念装新概念

## R — 原文

> 利用现成的基模……把新观念嫁接在已有的认知结构上。
> —— 第2章（p120-140）

> 大制作电影《异形》的宣传语是"太空版的《大白鲨》"。
> —— 第2章（p132）

## I — 自述

人无法直接理解全新的东西，只能把它挂到已知的东西上。所以"讲不清"往往不是解释不够，而是**没有可供嫁接的基模**。

三种操作：

1. **高概念（X 版的 Y）**：用一句话把新事物锚定到受众已知的类型上。"太空版的《大白鲨》"——受众立刻拿到类型、节奏、卖点三样信息。
2. **插旗法**：先找受众脑中已有的认知（一面"旗"），把新概念插上去。要求这面旗必须**同时具备**你需要的全部关键属性，否则会带来错误联想。
3. **生成性类比**：判断类比好坏的标准不是"像不像"，而是"能不能长出新的、正确的结论"。好类比会自动告诉你边界在哪里——"给每个员工配个实习生"这个类比自带"实习生不能签合同"这条推论。

还有两种配套手法：**贯穿式情境**（用一个长案例承载全部抽象概念，如数学课用"开一家店"贯穿全课）、**伯乐之眼**（管理者戴上"核心观点眼镜"，在杂乱素材里认出可用的类比）。

关键风险：**类比的边界就是它的谎言**。任何类比都会在某些维度上失效，所以必须同时告诉对方"这个类比的哪里不成立"。

## A1 — 书中案例

**《异形》= 太空版《大白鲨》**
- 问题：一部难以归类的科幻恐怖片，怎么让制片人和观众秒懂。
- 做法：一句话锚定到已知类型。
- 结果：一句话完成类型、成本预期、目标观众三重沟通。

**迪士尼的"演员"**
- 问题：怎么让清洁工理解自己的工作不只是扫地。
- 做法：把岗位重新锚定为"演员"（在舞台上，观众在看）。
- 结果：清洁工开始主动与游客互动、注意自己在园区里的表现。

**贯穿式情境的数学课**
- 问题：抽象公式记不住、用不上。
- 做法：一个长情境贯穿全课（我们要开店，需要算成本、定价、面积）。
- 结果：每个公式都挂在同一个具体情境上，学生能自己调用。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 要向完全不懂的人解释一个新概念/新业务/新技术。
2. 起了很多比喻，但不确定哪个好。
3. 新方案"听不懂"，需要一句话让人抓住。
4. 要给一个抽象原则找一个可感知的载体。

**语言信号**
- 中文：`怎么解释` `打个比方` `用什么类比` `一句话说清` `怎么向小白解释` `这个比喻好不好` `pitch 一句话` `怎么定位` `跟投资人怎么介绍` `像什么` `是中国的 XX 吗`
- 英文：`explain like` `analogy` `it's like X for Y` `high concept` `how would you describe` `positioning`

**与相邻能力的区分（初稿）**
- 与 `concretize`：本能力做**结构移植**（用已有结构承载新结构），具体化做**感官落地**（用画面承载概念）。解释复杂系统用本能力，让要求可执行用具体化。
- 与 `curiosity-gap`：类比常同时降低门槛（填缺口）和制造意外（打破预期），但它的核心功能是"给地基"，不是"抓注意"。
- 与 `core-message`：核心是"留什么"，类比是"怎么让对方接住"。先有核心才有类比，否则会做出一个漂亮但跑题的比喻。

## E — 执行步骤

1. **写出新概念的关键属性**（3–5 条）。完成标准：每条都是"必须保留，否则概念就变了"。
2. **找候选基模**（≥3 个）。来源：受众熟悉的行业、日常经验、已有产品类别。完成标准：每个候选能覆盖第 1 步的哪些属性（列表对照）。
3. **筛掉错误联想**：对每个候选问"它会让人误以为什么"。完成标准：写出每个候选的失效维度。
   - 判停点：若所有候选都漏掉关键属性 → 不要硬用类比，改用 `concretize` 给一个具体场景。
4. **生成性测试**：用这个类比推导一条**新结论**（书里没说的）。若推出来的结论是错的 → 类比不合格，回步骤 2。完成标准：至少一条正确的新推论。
5. **配边界句**：写一句"这个类比在哪里不成立"。完成标准：这句话能被直接放到材料里，且不削弱说服力。
6. **压成一句**：`这是 X 版的 Y，区别在于 Z`。完成标准：外行听完能复述，内行听完不反驳。

## B — 边界

**不要用**
- 概念本身高度依赖精确性且错误代价高时（医疗机制、法律要件）：类比会被当成定义。
- 受众群体基模差异极大时（跨文化/跨代际）：一个类比可能只对一半人生效。

**书中警告的失败模式**
- 类比不承载结构，只做装饰（"像火箭一样快"）——生成不出任何新结论。
- 基模选错导致错误联想（把"平台"讲成"市场"，听者以为你要做交易）。
- 用类比替代论证：类比能解释，不能证明。

**容易混淆**
- ≠ 修辞比喻（比喻美化，类比承重）
- ≠ 举例（例子是实例，类比是结构映射）
- 与 `concretize` 的分界：承载物是"结构"还是"感官"。

**作者盲点（阶段 0 批判）**
本书假设受众的基模是共享的，但基模本身就是**知识诅咒的另一面**：一个对你是常识的参照物（《大白鲨》、实习生），对另一代人可能毫无意义。使用前必须确认参照物在对方经验里真实存在——否则类比会变成第二次知识诅咒。
