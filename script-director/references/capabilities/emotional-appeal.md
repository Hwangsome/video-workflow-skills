# emotional-appeal · 唤起感受

## R — 原文

> 统计数字并不能激起任何情绪。研究表明，人们总是更可能对一个人产生感觉，而不是对一群人。
> —— 前言（p20-21）

> 它认为人是基于身份认同来做决策的。人们会问自己：“像我这样的人会怎么做？”
> —— 第5章（p301）

> 大多数人回答第三种——这让人感到备受尊重。……我们认为自己是受自我尊重的驱使，而别人则是受金钱驱使。
> —— 第5章（p292）

## I — 自述

"同意"不等于"在乎"。理性论证能让人点头，但点头不会产生行动——因为不动也不疼。

唤起感受有三层，顺序不能乱：

**第一层：从语义到感觉。** 把"这件事很重要"换成"这件事让谁难受"。判据是对方会不会皱一下眉。做法是把抽象规模换成一个人：不是"每年 X 万人"，而是"一个名字、一个下午、一次没人接的电话"。

**第二层：跳出马斯洛的"地下室"。** 绝大多数沟通只诉诸生理、安全、金钱这几个底层需求，因为说服者默认对方是经济人。但实验显示：人认为自己受尊重驱动，却认为别人受金钱驱动——这个系统性误判直接导致了大量失败的激励设计。

**第三层：诉诸身份，而不只是利益。** 人做决定时问的是"像我这样的人会怎么做"。身份认同自带行为约束：消防员不清理现场不是因为违规，而是因为"那不是我们"。这比任何 KPI 都强，但也更难建立——它要求具体到岗位日常，而不是喊价值观。

一条操作禁忌：**别在同一段里混用统计与情感**。数字启动计算，画面启动感受，同时给会让人不知道该算还是该哭，最后两个都不做。

## A1 — 书中案例

**特蕾莎修女效应**
- 问题：公益募款用"非洲有数百万儿童缺乏清洁饮水"的统计，捐款意愿低。
- 做法：改成一个孩子的照片和一个具体处境。
- 结果：捐款显著上升；而加入统计数字后，捐款反而下降——因为规模感把人推远。

**消防员的身份认同**
- 问题：如何让队员在火场后主动清理现场。
- 做法：把"清理现场"从规定变成身份的一部分——"我们不是那种把烂摊子留给别人的人"。
- 结果：不需要监督，行为稳定复现。

**飞马食堂的厨师**
- 问题：医院食堂按流程供餐，病人吃不下。
- 做法：让厨师把职责重新定义为"喂饱病人"而不是"按时出餐"。
- 结果：厨师主动改配方、改摆盘、改送餐时间——身份一变，行为链条全变。

**1000 元奖金的三种说法**
- 问题：同一笔钱怎么讲最有驱动力。
- 做法：三种定位——能买什么 / 带来的安定感 / 公司肯定你的重要性。
- 结果：多数人说自己受第三种驱动，却预测别人受第一种驱动。这个错位几乎解释了大公司激励政策的普遍失效。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 道理都讲清了，对方"同意但不做"。
2. 要推动一件事，但只能靠考核和 KPI，成本很高。
3. 写的是公益/安全/健康/内部倡议类内容，需要"在乎"而不只是"知道"。
4. 激励方案设计了但没人买账。

**语言信号**
- 中文：`怎么让人重视` `大家不在乎` `说了没用` `怎么打动人` `怎么让人愿意做` `员工没感觉` `怎么引起共鸣` `怎么让领导重视` `激励没效果`
- 英文：`make them care` `emotional appeal` `why should they care` `drive engagement` `get buy-in` `motivate`

**与相邻能力的区分（初稿）**
- 与 `concretize`：具体化是手段（让人看见），情感是目的（让人在乎）。看见不一定在乎——一个精确的数字也可能毫无感觉。所以本能力必须单独做"身份/感受"这一步。
- 与 `story-power`：故事是最常用的情感载体，但故事还额外提供行动脚本。只需要"在乎"时用本能力，需要"知道该怎么做"时用故事。
- 与 `credible-evidence`：两者互斥于同一段（书里明确警告）。

## E — 执行步骤

1. **确认缺的是"在乎"而不是"理解"**。问一句"他是不知道，还是知道了但不做"。完成标准：能把问题归到"动机"而不是"信息"。归不到 → 转 `concretize` 或 `credible-evidence`。
2. **把规模换成一个人**。写出一个具名（或可指认）的人 + 一个具体时刻 + 一个具体后果。完成标准：这段文字能让读者说出"那个人当时……"，而不是"这个比例……"。
3. **做身份定位**。回答"这件事是'像我这样的人'会做的吗"。写法：用"我们不是……的人"或"这个岗位上的人不……"。完成标准：这句话能用来否决一个具体行为，而不只是表态。
4. **检查马斯洛层级**：确认诉求没有停在金钱/安全层（除非确实只有这一层可用）。完成标准：能说出这件事触碰的是尊重、归属、学习还是审美需求。
5. **隔离**：把统计数字移到另一段或删掉。完成标准：本段内没有百分比、没有"据统计"。
6. **验收**：让一个目标受众读，观察反应。完成标准：他主动追问细节或说出自己的类似经历（= 有感受）；若他说"数据挺全的"，回步骤 2。

## B — 边界

**不要用**
- 需要冷静判断的技术/财务决策场景：情绪介入会降低决策质量，且会让人觉得被操纵。
- 数据本身是主角时（审计报告、实验结果）：此时应保证情感不污染证据段。
- 受众已经高度焦虑：再加强感受会引发回避而非行动。

**书中警告的失败模式**
- 用统计代替感受（见 `ce05`、`ce16`）。
- 假设别人住在马斯洛"地下室"，只谈钱（见 `p17`）。
- 统计与情感同段混用，互相抵消（见 `p19`）。
- 把"感觉"做成"煽情"：加形容词不是唤起感受（见 `g13`）。

**容易混淆**
- ≠ 煽情（加情绪词）／≠ 共情（那是能力，这是设计）
- 与 `story-power` 的分界：需要脚本用故事，只需要动机用本能力。

**作者盲点（阶段 0 批判）**
本书对情感诉求的道德边界讨论不足。"身份认同"是极强的工具，也极易被用于制造对立（"我们 vs 他们"）。使用时必须提示：若身份诉求以贬低外群体为代价，短期有效、长期反噬。此外在中文职场，直接诉诸"你是什么样的人"可能被读成道德绑架，需降级为"我们这个团队通常怎么做"。

## 相关能力

- 依赖：`concretize`（没有具体的人，就没有感受）
- 组合：`story-power`（故事承载情感）、`shared-vocabulary`（身份需要一套词来表达）
- 对比：`credible-evidence`（同一段里互斥）
