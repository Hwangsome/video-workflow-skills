# concretize · 具体化

## R — 原文

> 你能凭感官去认知某样东西，那就是具体的。“V8 发动机”是具体的，“高性能”则是抽象的。……大多数人熨衬衫则是具体的。
> —— 第2章（p112-113）

> 以谚语为例，抽象的真理每每会编为具体的词句。
> —— 前言（p20）

## I — 自述

具体不是"细节多"，而是**能被感官或动作认领**。

判据很简单：这句话能不能被画出来、演出来、被人做一遍？"高性能"不能；"V8 发动机"能。"客户体验不佳"不能；"客户打了三次电话都没人接"能。

为什么有效：大脑记住的是钩子，抽象概念没有钩子。具体的东西自带画面、自带情绪、自带可验证性——它同时解决了记忆、感受、可信三个问题，这也是它在六原则里性价比最高的原因。

三个常用手法：

1. **换成可感官的判据**。把"要快要稳"换成"新人 30 分钟能改对一个 bug"。判据可以被观察、被计时、被当场违反。
2. **借一个已经具体的载体**。用一个具体物件、一个具体场景、一个具体的人，让抽象概念挂在它身上（布朗眼睛实验、辛普森的手套）。
3. **把数字落到一个人身上**。数字是抽象的最高形式，必须还原成"一个具名的人 + 一个具体处境"才能被感知。

关键边界：具体必须**支持核心**。生动但不指向核心的细节叫"诱惑性细节"，越生动越有害——它抢占记忆位，把核心挤掉。

## A1 — 书中案例

**牙买加的"别让蚊子叮你"**
- 问题：登革热防治宣传讲了发病率、传播途径、伊蚊学名，效果很差。
- 做法：把全部信息压成一个具体动作——"别让蚊子叮你"，并配合可执行的场景提示。
- 结果：行为改变率显著高于知识普及型宣传。

**爆米花：37 克 vs 一桶对比图**
- 问题：用"含 37 克饱和脂肪"警告观众，无人有反应——37 克无法被感知。
- 做法：改成"一桶爆米花 = 一顿正餐的饱和脂肪总量"，用一餐饭做参照。
- 结果："37 克"这类数字引不起任何情绪，换成可感知的对比后才产生厌恶感。

**布朗眼睛 / 蓝眼睛实验**
- 问题：如何让小学生理解"被歧视"是什么感觉。
- 做法：老师按眼睛颜色把全班分成两组，一天内给一组特权、另一组限制。
- 结果：孩子用一天的身体经验理解了抽象概念，多年后仍记得——这是"用经历承载概念"的极端形态。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 写出来的东西"正确但没人记得住"，需要换成能看见的说法。
2. 要解释一个专业概念给外行/老板/客户听。
3. 培训/宣导材料讲了很多道理，但没人照着做。
4. 有一堆数据想用，但知道"讲数字没人听"。

**语言信号**
- 中文：`太抽象了` `说人话` `怎么讲才能让人记住` `举个例子` `落地一点` `具体点` `怎么让外行听懂` `这个数字怎么讲才有感觉` `数据讲出来没反应` `太虚了`
- 英文：`too abstract` `make it concrete` `explain like I'm five` `give me an example` `make it tangible` `how do I make this land`

**与相邻能力的区分（初稿）**
- 与 `emotional-appeal`：具体化是**让人看见**，情感是**让人在乎**。具体的画面常常顺带产生感受，但如果目标是"让他行动/心疼/愤怒"，需要额外做身份与感受的设计。
- 与 `credible-evidence`：具体化让内容可感知，可信让内容可验证。一个具体细节可能同时具备两者（"你自己去试"），但只有需要"说服怀疑者"时才走可信路径。
- 与 `core-message`：核心先定"留什么"，具体化再定"怎么让它被看见"。顺序不能反——先具体化容易得到一堆生动的碎片。

## E — 执行步骤

1. **抓出抽象词**。逐句标出所有无法被感官认领的名词与形容词（价值、协同、机制、高效、优化、体验）。完成标准：清单化，每条注明它想表达什么。
2. **为每个抽象词找一个"可被认领"的替代**，三选一：
   - 可观察的判据（能被看见/计时的行为）
   - 一个具体的人 + 一个具体处境
   - 一个具体物件/场景作为载体
   完成标准：替换后的句子能被画成一张草图，且画出来别人能看懂。
3. **做"诱惑性细节"筛查**：对每个新增细节问"删掉它，核心会受损吗"。不会 → 删。完成标准：剩下的每个细节都能指向核心的一句话。
4. **落地测试**：把改写后的版本给一个不了解背景的人，让他复述"要做什么"。完成标准：他能说出一个具体动作，而不是一个形容词。
   - 判停点：若他复述出的是形容词，回到步骤 2；若他复述出的动作偏离核心，回到步骤 3 删细节。

## B — 边界

**不要用**
- 需要精确性的场合：法律条款、临床剂量、财务口径。这里"够用"不能替代"准确"，具体化会让表述失真。
- 抽象本身就是产品时（哲学论述、艺术阐释），强行具体化会削掉它的开放性。

**书中警告的失败模式**
- 诱惑性细节：生动但不支持核心，反而挤掉核心（见 `p13`）。
- 追求精确导致"准确到无用"：为了涵盖所有情况而不断加限定，最后无法指导行动（见 `ce04`）。
- 用细节堆砌代替具体：细节多不等于能被感官认领（见 `g08`）。

**容易混淆**
- ≠ 举例（例子可能只是把抽象换成另一个抽象）
- ≠ 通俗化（降词汇门槛，不改变结构）
- 与 `credible-evidence` 的分界：目标是"让人记住/有感觉"→ 本能力；目标是"让人相信这是真的"→ 可信凭证。同一句话可以两边都用，但要**分段**，否则互相抵消。
- 与 `high-concept-analogy` 的关系：那个是用**已有概念**承载新概念（结构移植），本能力是**用感官**承载概念。若用户需要的是"找一个类比/一句'X 版的 Y'"（尤其向投资人或完全外行做整体定位），走 `high-concept-analogy`（在来源路由入口内）。

**作者盲点（阶段 0 批判）**
本书对"具体"的推崇近乎无条件，但在**跨文化/跨专业**场景中，一个具体的画面可能只在一部分人脑中成立（"V8 发动机"对不开车的人是抽象）。使用时必须确认该画面在目标受众的经验范围内，否则具体化会变成新的知识诅咒。

## 相关能力

- 依赖：`core-message`（先有核心，才知道哪些细节该留）
- 组合：`emotional-appeal`（具体是唤起感受的前置）、`credible-evidence`（具体细节常成为可检验凭证）
- 对比：`high-concept-analogy`（感官承载 vs 结构移植）
