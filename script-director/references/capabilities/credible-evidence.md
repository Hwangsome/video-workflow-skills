# credible-evidence · 可信凭证

## R — 原文

> 利用了“反权威”的可信度……因为对方没有动机说谎，所以有时候反权威比权威更加可信。
> —— 第4章（p310-320）

> 你要是拿到了，就说明你在那儿能成功（西纳特拉测试）。
> —— 第4章（p302）

> 可检验性认证是威力极强的……
> —— 第4章（p292）

## I — 自述

可信度的本质不是"说话的人可靠"，而是"**结论可以被受众自己检验**"。

这解释了一个反直觉现象：权威背书常常无效，因为受众会自动打折——你和我有利益关系，你的话我不信。而一个**没有动机说谎的人**（反权威）反而更可信：一个爱吃汉堡的大胖子推荐低脂食品，说服力强过十个营养学家。

五类可用凭证，按可靠性排序：

1. **可检验性认证**：让受众自己动手试（"你不信就去量一下"）。最硬，因为它把裁判权交出去了。
2. **西纳特拉测试**：一个极端到无可辩驳的案例（"把啤酒从牙买加运到迈阿密"）。它一次证明全部能力，让"你凭什么"这个问题消失。
3. **反权威**：立场与结论相反、却仍然这么说的人。
4. **生动细节**：具体到无法编造的细节——但必须支持核心，否则是诱惑性细节。
5. **人性化统计**：把数字落到一个人身上。

两条操作禁忌：**统计与情感不要放在同一段**（会互相抵消，读者不知道该算还是该哭）；**数据是输入不是输出**（给它作用的对象，别只给它一个数）。

## A1 — 书中案例

**帕姆·拉芬与反权威**
- 问题：健康宣传讲低脂饮食，受众觉得"专家当然这么说"。
- 做法：让一个明显超重、爱吃汉堡的人来讲"我就是这么吃，结果医生说我要出事"。
- 结果：说服力超过专家——因为他没有动机美化。

**顺风物流与西纳特拉测试**
- 问题：物流公司凭什么让客户相信"我们什么都能运"。
- 做法：讲一个极端案例——把一箱啤酒从牙买加按时运到迈阿密，全程合规、温度达标。
- 结果：客户不再问能力问题，只问价格——"如果你那儿能成功，到哪儿都能成功"。

**科维与人性化统计**
- 问题：统计数据无法引发共鸣。
- 做法：把统计数字还原成一个具体人的日常处境（把"每年 X 人"变成一个人的一天）。
- 结果：数字获得了可感知的重量。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 方案/预算/立项要说服一个多疑的决策者。
2. 讲的内容真实但对方不信，越解释越像辩解。
3. 手上只有统计数字，知道讲了没人听。
4. 自己的权威不够（新人、跨部门、乙方），需要外部凭证。

**语言信号**
- 中文：`怎么让人相信` `没人信我` `说服老板` `数据没人看` `怎么证明` `没有案例怎么办` `对方觉得我在吹` `用户不信任我们` `怎么建立可信度`
- 英文：`how do I convince` `build credibility` `they don't believe me` `social proof` `proof point` `how to substantiate`

**与相邻能力的区分（初稿）**
- 与 `emotional-appeal`：可信解决"该不该信"，情感解决"在不在乎"。两者混在同一段会互相抵消（书里明确警告）——这本身就是最好的区分信号。
- 与 `concretize`：具体化让内容可感知，可信让内容可验证。有些细节两者兼具，但目标不同：一个求记住，一个求相信。
- 与 `counter-stickiness`：对方只是**怀疑**（缺凭证）→ 本能力；对方已经有**一个相反的强观念**（谣言、成见）→ 以黏制黏。这个分界是本能力最常被误用的地方。

## E — 执行步骤

1. **定位怀疑的具体形状**。问清楚对方到底不信哪一句：是"你说的是真的吗"、"你做得到吗"、还是"这对我也成立吗"。完成标准：写出那一句被怀疑的话。
2. **选凭证类型**：
   - 不信"是不是真的" → 可检验性认证（给一个他能自己验的方法）
   - 不信"你做得到" → 西纳特拉测试（一个极端案例）
   - 不信"你会为我好" → 反权威（一个与他立场相反的人）
   - 不信"这有多严重" → 人性化统计（一个人 + 一个处境）
   完成标准：写清选了哪类、为什么这一类能对上他的怀疑。
3. **做压力测试**：把凭证交给一个和决策者相似的人，问"这能说服你吗，还差什么"。完成标准：他不再追问同一类问题。
   - 判停点：若他追问的是"这跟我有什么关系"，说明选错类 → 回步骤 2 换"人性化统计"。
4. **隔离**：确认这一段里没有混入情感诉求或号召。完成标准：这一段只承担"可信"一个功能。
5. **收尾**：删掉所有自我背书（"我们很专业""行业领先"）。完成标准：剩下的每一句都能被对方验证或反证。

## B — 边界

**不要用**
- 对方已经相信、只是需要执行方案时——继续加凭证会显得心虚，反而降低可信度。
- 需要快速决策的低风险场景：过度举证会拖慢节奏（"这条路径的成本高于收益"）。

**书中警告的失败模式**
- 权威依赖：只靠职级、规模、历史（见 `ce15`）。
- 统计与情感混用：互相抵消（见 `p19`）。
- 把数据当输出：只给数字，不给它作用的对象（见 `p11`、`p12`）。
- 用辟谣对抗已有观念：那是 `counter-stickiness` 的领域，用凭证会失败（见 `ce11`）。

**容易混淆**
- ≠ 权威背书（多数情况下更弱）
- ≠ 举例（例子不是凭证，能自验的才是）
- 与 `concretize` 的分界：目标只是"让这个数字被记住/有感觉"→ 具体化；目标"让对方相信这个数字是真的、或据此下判断"→ 本能力。
- 与 `counter-stickiness` 的分界：**对方有没有一个已成立的相反叙事**。有 → 覆盖；没有 → 举证。**单个人（例如老板）的一次性怀疑不是"相反叙事"**，那仍然归本能力。

**作者盲点（阶段 0 批判）**
本书假定"可验证"总是优于"权威"，但在**专业门槛极高**的领域（医疗、航空、法律），受众没有能力验证，此时权威与制度性保证仍不可替代。另外在中文职场，直接给上级"你自己去验"可能被视为挑战，需要包装成"我们一起看一组数"。

## 相关能力

- 依赖：`core-message`（先知道要证明哪一句）
- 组合：`concretize`（可检验凭证几乎总是具体的）、`emotional-appeal`（举证后另起一段再解决"在乎"）
- 对比：`counter-stickiness`（对方无相反叙事 → 举证；有 → 覆盖）
