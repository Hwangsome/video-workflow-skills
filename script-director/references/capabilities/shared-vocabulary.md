## I — 自述

战略落不了地，通常不是没人认同，而是**在具体决策时没有可用的判断依据**。文件里写的是"差异化、以客户为中心"，但面对"这个棋盘要不要粘在一起"这种问题时，它一句话也说不上。

共同语汇的做法：把战略压成 **3–5 个形容词**，让它们成为组织日常的通用语。

四个成立条件，缺一不可：

1. **少**：3–5 个，能被记住。超过 7 个就无法在日常对话里调用。
2. **具体到能判断**："聪明"能判断，"创新驱动"不能。
3. **能用来否决**：这是最硬的一条。合格的语汇必须能让一线说出"这个方案不够 X"，并且管用。
4. **双向可用**：下级能用它反驳上级。CHIFF 之所以成立，正是因为中国制造商拿它顶回了创始人的设计——如果只有总部能用，它就是标语而不是语汇。

与"内部黑话"的分界就在这里：黑话是**分类标签**（可以互相替换而不影响任何决策），语汇是**价值判断**（能决定做不做）。

## A1 — 书中案例

**颅骨公司（Skullcandy）的 CHIFF**
- 问题：差异化战略只存在于创始人脑内，员工、供应商、渠道各按自己的理解做事。
- 做法：把战略压成五个形容词——聪明（smart）、优质（quality）、创新（innovative）、友好（friendly）、有趣（fun），合成 CHIFF，变成内部通用语。
- 结果：中国制造商用 CHIFF 反驳创始人自己的设计（粘在一起的棋子"既不创新也不优质"），并给出更好方案。一个词同时破解了三道障碍：知识诅咒、决策瘫痪、缺乏共同语言。

**西南航空"全球票价最低"**
- 问题：每天面对大量"要不要加这项服务"的提案。
- 做法：一句话成为所有提案的否决依据。
- 结果：几十年战略一致性。

**陆军"指挥官意图"作为跨层级语言**
- 问题：命令无法覆盖所有情况。
- 做法：每道命令前加一句意图。
- 结果：基层在无指令时也能对齐方向——这说明"共同语汇"不只适用于形容词，也可以是一句话的意图。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 战略/价值观文件写了，但一线该怎么做还是不知道。
2. 各部门对同一件事的判断标准不一致，会议反复吵。
3. 想给团队一套"能用来做取舍"的说法，而不是又一套口号。
4. 内部术语太多、太虚，需要重整。

**语言信号**
- 中文：`战略落地` `怎么让全员理解战略` `统一语言` `价值观怎么落地` `判断标准不一致` `内部术语太多` `怎么让一线自己做决定` `口号没用` `共识怎么建立`
- 英文：`shared vocabulary` `strategy execution` `alignment` `decision principles` `operating principles` `common language`

**与相邻能力的区分（初稿）**
- 与 `core-message`：核心是**一句话**（给方向），共同语汇是**一组词**（给日常判断工具）。一句话管"往哪走"，几个词管"这个能不能做"。
- 与 `emotional-appeal`（身份认同）：语汇常承载身份（"我们不是那种……的公司"），但本能力的产出是**可判定的词**，不是情感。
- 与 `stickiness-audit`：体检针对单份材料，本能力针对组织的长期语言系统。

## E — 执行步骤

1. **收集真实的两难**：列出 3–5 个组织里反复出现的具体取舍（"要不要接这个定制单""这个功能要不要加"）。完成标准：都是真实发生过的争论，不是假设。
2. **为每个两难写出判断依据**：如果只能用一个形容词决定，是哪个。完成标准：每个两难都能被一个词偏向。
3. **收敛到 3–5 个词**：合并同义、删掉不可判定的（"卓越""协同"）。完成标准：每两个词之间不能互相替换而不改变判断。
4. **做否决测试**（关键）：拿一个真实提案，用这几个词说"不行"，看是否成立、是否有人服。完成标准：至少一次成功否决，且被否决方接受。
   - 判停点：若能否决但没人服 → 词是对的，但缺少公开使用的先例，转步骤 5。
5. **让下级先用**：设计一个场景，让一线用这些词反驳一个上层方案。完成标准：发生过一次"下级用词否掉上级方案"的实例（这是语汇成立的唯一硬证据）。
6. **写成一页**：3–5 个词 + 每个词一句定义 + 一个"不够 X 的例子"。完成标准：新人读完能独立判断。

## B — 边界

**不要用**
- 组织规模太小（<10 人）且靠日常对话就能对齐：加一套词只会增加仪式感。
- 战略本身还没想清楚：语汇会把模糊固化，且极难修改。
- 需要精确规则约束的场景（安全、财务合规）：这些要用制度，不能用形容词。

**书中警告的失败模式**
- 用分类标签冒充价值判断（见 `ce14`）：可以互换而不影响决策的词是无效的。
- 词太多：超过 5 个就没人用。
- 只有高层使用：一旦只用于汇报，它已退化为标语。
- 把愿景宣言当战略（见 `ce12`）：宣言不可证伪。

**容易混淆**
- ≠ 价值观标语（标语表态，语汇判断）
- ≠ 内部黑话（黑话分类，语汇取舍）
- 与 `core-message` 的分界：一句话 vs 一组词。

**作者盲点（阶段 0 批判）**
CHIFF 这类成功案例依赖一个前提：**高层愿意被自己的词反驳**。多数组织里，语汇一旦被用于质疑上级，就会被重新解释或废弃。因此本能力在使用时必须先确认"权力是否允许被否决"——否则产出的是又一套漂亮的空话。这一点书中未讨论。

## 相关能力

- 依赖：`core-message`（先有一句话的方向）
- 组合：`emotional-appeal`（词承载身份）、`stickiness-audit`（用体检标准检验每个词是否可感知）
- 对比：`core-message`（一句话 vs 一组词）
