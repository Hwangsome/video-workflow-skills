## I — 自述

让人"知道"最快的方式不是讲，是让他**在脑内或现场跑一遍**。

关键在于区分两种模拟：

- **结果模拟**：想象"成功之后的样子"。它只激活奖赏回路，不激活路径。更糟的是它会制造"已经达成"的虚假完成感，**反而降低行动率**——这是本书最反直觉的发现之一。
- **过程模拟**：把未来拆成一步步具体动作，并预演卡点。它激活的是执行路径，因此能提高行动率、改善技能、调节情绪。

所以"想象你站在领奖台上"这类动员是无效甚至有害的；有效的是"他如果这么说，你就那么答"。

三种落地形态：

1. **脑内过程模拟**：让当事人自己写出步骤与卡点（不是听你讲）。
2. **现场演练**：角色扮演、桌面推演、沙盘。
3. **可亲历的体验设计**：让对方亲手做一次（这是"以黏制黏"里的黏性行动）。

## A1 — 书中案例

**结果模拟 vs 过程模拟实验**
- 问题：哪种心理预演更能促进行动。
- 做法：一组想象自己拿到好成绩的场景，一组想象自己如何安排复习的过程，对照组不做模拟。
- 结果：过程模拟组行动率最高；结果模拟组反而低于对照组。

**培训中的演练**
- 问题：课堂讲授的知识回到岗位就忘。
- 做法：加入角色扮演与现场演练，让学员在安全环境里跑一遍真实情境。
- 结果：迁移率显著提高，因为知识被绑定到了具体场景。

**英格索兰的"拖拉测试"（体验式）**
- 问题：不相信塑料件够耐用。
- 做法：直接把样品绑在车后拖着跑。
- 结果：一次亲历胜过所有强度测试报告——这是"体验"的极端形态。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 培训/带新人/推行新流程，讲了很多遍还是不会。
2. 要准备一次高风险对话（谈判、绩效面谈、危机沟通）。
3. 想让团队对某个风险"真有感觉"，而不是纸面同意。
4. 自己在准备一件事，容易陷入"想象成功"的空转。

**语言信号**
- 中文：`怎么准备` `演练` `角色扮演` `培训没效果` `怎么让团队有感觉` `沙盘` `预演一下` `怎么练` `想象成功`（需纠正）
- 英文：`role play` `dry run` `rehearse` `tabletop exercise` `simulation` `walk through` `mental rehearsal`

**与相邻能力的区分（初稿）**
- 与 `story-power`：故事是**用别人的经历**模拟（成本低、可规模化），本能力是**自己跑一遍**（迁移率高、成本高）。先用故事建立脚本，再用演练固化。
- 与 `concretize`：具体化让内容可感知，模拟让内容可执行。一个画面能被看见，一个序列能被跑。
- 与 `emotional-appeal`：模拟会自然产生感受（尤其预演失败时），但它的目标是行为，不是情绪。

## E — 执行步骤

1. **确认问题不是"不知道"**。问"他是不知道步骤，还是知道但不做"。完成标准：能指出具体缺的是哪个环节的动作。
2. **把场景切成 3–6 个节点**。每个节点写"对方会做什么/说什么"。完成标准：节点覆盖从开场到收尾，无跳跃。
3. **逐节点写应对**："如果他 X，我就 Y"。完成标准：每个节点都有一句可执行的话，而不是一种态度。
   - 判停点：若某节点写不出应对 → 标记为"未知"，并在演练中优先跑它（未知才是风险点）。
4. **跑一遍**（真人或出声自述）。完成标准：全程不卡壳；卡壳处即为需要补的节点。
5. **只记录过程，不评价结果**：演练后问"哪一步最不确定"，而不是"你觉得能成吗"。完成标准：产出一份"待补节点清单"。
6. **固化**：把最终版压成一页对照表（场景 → 应对）。完成标准：别人拿这张表也能跑。

## B — 边界

**不要用**
- 时间极紧、必须先行动的场合：演练会变成拖延。
- 场景本身不可预演（高度依赖临场创造）：过度预演会让人僵化，失去应变。
- 团队已经过度谨慎时：再加演练会强化回避。

**书中警告的失败模式**
- 只做结果模拟（想象成功）：降低行动率（见 `ce08`）。
- 把演练做成表演：大家演得开心，没产出待补节点。
- 用"我讲过了"替代"他跑过了"（见 `ce10`）。

**容易混淆**
- ≠ 计划（计划是纸面的，模拟是在脑内/现场跑一遍）
- ≠ 愿景畅想（方向相反：一个是路径，一个是奖赏）
- 与 `story-power` 的分界：别人的经历 vs 自己的经历。

**作者盲点（阶段 0 批判）**
本书的模拟研究多来自个体技能与健康行为领域，**团队级、组织级**的演练效果证据较弱，且存在"演练过度导致形式化"的现实问题（很多企业的消防演练即为例证）。用于组织场景时，需强调"演练必须包含意外注入"，否则会固化成流程表演。
