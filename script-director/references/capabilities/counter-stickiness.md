# counter-stickiness · 以黏制黏

## R — 原文

> “我们可负担不起蚯蚓。你们要知道，一磅肉饼要价1.5美元，请专人去抓蚯蚓再剁碎，一磅那得花6美元！”
> —— 附录1-3（p445）

> 黏性无法拔除，只能以黏制黏。
> —— 附录1-3（p443-449，原文论断）

## I — 自述

当对方脑中已经有一个**黏性很强的错误观念**（谣言、成见、行业误解），常规沟通会失效，而且会反噬。

原因有两个：
1. **否认必须先复述。** 你说"最近传的 X 不是真的"，听者记住的是 X。否定词不参与记忆，主张参与。
2. **强弱不对等。** 谣言有画面、有情节、有情绪；你的澄清只有条款。强弱不对等时，弱的一方被完全忽略——这不是被反驳，是被无视。

所以只有一条路：**用一个更黏的东西去覆盖它**，而不是去拔它。三种做法：

1. **造一个更黏的观念**：用具体、可验证、有反差的事实压过去（麦当劳的"蚯蚓成本 6 美元一磅"）。
2. **写一个更荒诞的仿作**：让原谣言失去严肃性（好时光病毒的戏仿版）。
3. **设计一个黏性行动**：不辩论，让人亲眼看/亲手做（汽车可靠性大赛）。

判据只有一条：**新东西必须比旧东西更有画面、更有情节、更可验证**。否则不如不说。

## A1 — 书中案例

**麦当劳与蚯蚓汉堡谣言**
- 问题：谣言传了十几年，公司多次声明"毫无根据"，毫无效果。
- 做法：CEO 改用成本计算反讽——"一磅肉饼 1.5 美元，请人抓蚯蚓剁碎一磅要 6 美元，我们可负担不起蚯蚓。"
- 结果：一句有画面、有数字、有反差的话，让谣言失去立足点。此前 1978 年的"毫无根据"式声明完全无效。

**好时光病毒（Good Times virus）**
- 问题：一封"转发此邮件会导致硬盘损坏"的连锁信疯狂传播。
- 做法：系统操作员写了更荒诞的仿作（会让冰激凌化掉、让旧情人打来电话）。
- 结果：戏仿版流传更广，原谣言失去严肃性，逐渐淡出。

**汽车业的可靠性大赛**
- 问题：公众坚信某类车"容易爆炸"。
- 做法：不辩论"可爆物"，办可靠性大赛，让人亲眼看车爬山。
- 结果：17 年后公众认知改变——慢，但不可逆。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 有谣言/负面传闻在传，需要处理。
2. 团队/客户有一个根深蒂固的错误认知，讲事实讲不通。
3. 行业里有一个流行的错误做法，想纠正。
4. 辟谣反而让更多人知道了，需要换方式。

**语言信号**
- 中文：`辟谣` `有人在传` `怎么澄清` `他们就是不信` `根深蒂固的误解` `越解释越糟` `负面舆情` `怎么反驳` `客户有错误认知` `怎么纠正行业误区`
- 英文：`debunk` `rumor` `misconception` `counter-messaging` `pushback` `myth-busting` `damage control`

**与相邻能力的区分（初稿）**
- 与 `credible-evidence`：那个处理"没有成见的怀疑"（给凭证即可）；本能力处理"已有相反叙事"（给凭证会被吸进旧框架）。判据：**对方心里有没有一个现成的反面故事**。
- 与 `story-power`：本能力可以用故事，但故事在这里的任务是**覆盖**而不是**教学**。
- 与 `curiosity-gap`：不要对已有强观念者用悬念——他们不会好奇，只会确认自己是对的。

## E — 执行步骤

1. **判断是否真的需要覆盖**。问：对方只是不知道，还是已经有一个版本？完成标准：能复述出对方现在的版本（用他们的语言）。
   - 判停点：若对方只是不知道 → 转 `credible-evidence`，不要用重手段。
2. **找出旧版本的黏性来源**：它靠画面？靠情节？靠情绪？靠"内部消息"？完成标准：指出它最强的那一点。
3. **选覆盖方式**：
   - 有可计算的反差 → 更黏的观念（数字 + 画面，如蚯蚓成本）
   - 旧版本本身荒诞 → 荒诞仿作（让它失去严肃性）
   - 需要长期改变认知 → 黏性行动（让人亲历）
   完成标准：选一种，并说明它为什么能压过第 2 步找到的那一点。
4. **自检三条**：比旧版本更有画面吗？更有情节吗？更可验证吗？完成标准：三条全过；任一不过 → 回步骤 3 换方式。
5. **不要在材料里复述旧版本**。检查全文。完成标准：旧主张除了必要的指认，不出现第二次。
   - 例外：必须指认时才用最小指称（"那个说法"），不复述内容。
6. **配一条长期动作**：认知改变以年计（书中的例子是 17 年）。完成标准：给出一条可持续做、可累积的行动（而不是一次性声明）。

## B — 边界

**不要用**
- 谣言涉及法律/人身安全/合规红线：先走法务与官方渠道，本能力是辅助而非替代。
- 对方只是信息不足（没有成见）：用本能力会显得过度反应，反而暗示"这事很严重"。
- **单个人的一次性怀疑**（如"老板觉得这方案风险大"）：那不是已成立的反面叙事，属于 `credible-evidence` 的举证问题。本能力要求对方的怀疑**已经有版本、有画面、在流传**（谣言、行业误解、群体成见）。
- 需要精确澄清事实的场合（更正错误数据）：必须直接给准确数字，戏仿与反讽会造成新误解。

**书中警告的失败模式**
- 发"此为不实信息"式声明（见 `ce11`）：复述即曝光，且强弱不对等必输。
- 用更长的解释去对抗更短的谣言：长度不是黏性。
- 只做一次性动作：认知改变需要累积。

**容易混淆**
- ≠ 辟谣（辟谣是拔，本能力是覆盖）
- ≠ 公关话术（本能力要造一个**更好记的真相**，不是更圆滑的措辞）
- 与 `credible-evidence` 的分界：有无现成的反面叙事。

**作者盲点（阶段 0 批判）**
本书的三个案例都发生在"组织有能力持续投入"的前提下（麦当劳、汽车业用十几年）。对个人或小团队，这条路成本极高，可能不如"不回应、只服务好现有用户"。另外，荒诞仿作在中文语境里可能被读成"官方在嘲讽公众"，风险高于英文语境，需谨慎。

## 相关能力

- 依赖：`core-message`（覆盖物本身也必须有一个核心）
- 组合：`concretize`（覆盖物必须具体）、`simulate-experience`（黏性行动就是让人亲历）
- 对比：`credible-evidence`（无成见 → 举证；有 → 覆盖）
