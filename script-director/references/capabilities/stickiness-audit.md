# stickiness-audit · 黏性体检

## R — 原文

> 这个说法简单吗？……意外吗？……具体吗？……可信吗？……有情感吗？……是故事吗？
> —— 前言（p35）

> 要让创意产生黏性，有效而又持久，你必须得让观众：（一）集中注意听（二）听懂并记住（三）同意或相信（四）关心、在乎（五）能起而行动。
> —— 结语（p391-392）

> 当学生们回忆演讲内容时，63%的人记得故事，只有5%的人记得个别数据。
> —— 结语（p386）

## I — 自述

这是一张**改稿用的检查表**，不是一套生成方法。用法差别很大：生成是从零造，体检是拿现成材料逐项对表。

六问（简 / 奇 / 具 / 信 / 情 / 事）分别修沟通五步中的一步：

| 六原则 | 修的是哪一步 | 缺了会怎样 |
|---|---|---|
| 简单（核心） | 听懂并记住 | 记住了但记的是碎片 |
| 意外 | 集中注意听 | 根本没在看 |
| 具体 | 听懂并记住 | 听懂了但记不住 |
| 可信 | 同意或相信 | 觉得挺好，但不当真 |
| 情感 | 关心、在乎 | 同意，但不动 |
| 故事 | 能起而行动 | 想动，但不知道怎么做 |

两条必须记住的元规则：

1. **六项不是并列清单，必须服务同一个核心。** 六项齐全但核心不同，比缺三项更糟——它看起来很好，实际什么也没传出去。
2. **验收标准在接收端。** 不问"我讲得好不好"，问"他隔一天能复述出什么"。斯坦福实验里，讲得最流畅的人得分最高，内容却几乎无人记得——流畅度会伪造"已传达"的错觉。

还有一个使用前提：**先复现对方的视角**。所有诊断都可能被"知识的诅咒"污染——你会觉得"这已经很清楚了"。所以体检的第一步不是看材料，是写下"读者此刻知道什么"。

## A1 — 书中案例

**用六问体检两句"战略表述"**
- 问题：CEO 宣布"我们要实现股东价值最大化"，员工无反应。
- 做法：逐项问——简单？字数短但不像谚语。意外？不意外。具体？不具体。可信？只是因为出自 CEO 之口。有情感？没有。是故事？不是。
- 结果：六项全空。对照肯尼迪"十年内把人送上月球再平安接回来"，六项全中。差别不在措辞，在结构。

**斯坦福 1 分钟演讲实验**
- 问题：怎么判断一场演讲是否有效。
- 做法：学生分两组用数据论证相反立场，各讲 1 分钟并互评；10 分钟后突袭要求写出还记得的内容。
- 结果：讲得最流畅者得分最高，内容几乎无人记得；被记住的演讲都在讲故事、调动情感或只讲一个重点。结论：评估指标应当是"对方能复述什么"。

**附录的症状→解方对照表**
- 问题：知道"没黏性"，但不知道从哪儿下手。
- 做法：按症状定位——"听众走神"→ 意外；"记不住"→ 具体；"不信"→ 可信；"不动"→ 情感/故事。
- 结果：把六原则变成一条可执行的诊断路径，而不是六句口号。

## A2 — 未来触发

**用户会在这些情境下需要它**
1. 材料已经写完（方案/PPT/文案/课程/公告），想知道哪里不行。
2. 上次讲过一遍，这次要改，但不知道改哪儿。
3. 要给别人（下属/乙方/同事）的稿子提意见。
4. 想建立一套团队通用的改稿标准。

**语言信号**
- 中文：`帮我看看这份材料` `哪里不行` `怎么改` `有没有黏性` `讲完没人记住` `帮我改稿` `这份 PPT 有问题吗` `为什么没人转发` `诊断一下` `润色`（注意：润色诉求需要先确认是否只是文字层面）
- 英文：`review this` `give feedback on my deck` `why isn't this landing` `audit` `critique` `make this stick` `what's wrong with this pitch`

**与相邻能力的区分（初稿）**
- 与六张单项能力（`core-message` / `curiosity-gap` / `concretize` / `credible-evidence` / `emotional-appeal` / `story-power`）：体检负责**定位**，单项负责**修**。用户说"帮我诊断"→ 体检；说"帮我把这句改具体"→ 直接进单项。
- 与 `counter-stickiness`：体检针对"白纸"（对方没有成见）；若对方已有相反观念，体检的结论会误导——该先覆盖。
- 与普通润色：润色改字句，体检可能结论是"必须重写结构"。要敢于说出这句话。

## E — 执行步骤

1. **写下接收端画像**：读者是谁、此刻知道什么、会在什么场景读、读完要做什么。完成标准：三句话，且不含"他们应该知道"这类假设。
2. **抽取核心**：用一句话说出这份材料想让人记住什么。完成标准：这句话是**你写的**，不是从材料里抄的——如果抄不出来，说明材料没有核心（这是最常见的诊断结果）。
3. **六项打分**（每项 0/1，必须有证据）：
   - 简：有一句能复述的核心吗？
   - 奇：有一处打破预期吗？（指出具体哪一句）
   - 具：有一个能被感官认领的画面/判据吗？
   - 信：有一个对方能自己验证的凭证吗？
   - 情：有一个具体的人让他皱一下眉吗？
   - 事：有一个可演练的"遇到 X 就做 Y"吗？
   完成标准：每项后面写出材料里的原句作为证据；写不出即判 0。
4. **定手术级别**：
   - 缺 0–1 项 → 局部修补（补那一项）
   - 缺 2 项 → 结构调整（重排顺序、换开头）
   - 缺 ≥3 项 → **重写**，不要在原文上改字句
   完成标准：给出级别判断和理由。
5. **复述测试**（不可跳过）：找一个没参与的人，隔 1–4 小时让他复述。完成标准：他复述出的内容 = 第 2 步的核心。不等 → 回到第 4 步升级手术级别。
6. **输出修改清单**：按"改哪一句 → 改成什么 → 为什么"三列给出。完成标准：每条都能对应到六项中的一项，没有"语言更优美"这类无依据建议。

## B — 边界

**不要用**
- 用户只是想校对错别字/统一格式：体检会给出"重写"结论，超出需求。
- 只有一句话要评估（一句口号、一句标语、一个产品名）：那是 `core-message` 的活——体检的对象必须是**一整份材料**，单句没有"六项缺几项"可言。
- 内部记录、法律文件、参数表：不追求黏性，追求完整准确。
- 对方已有强相反观念（谣言、成见、政治阻力）：先 `counter-stickiness`，否则改得再好也没人接。

**书中警告的失败模式**
- 把"讲得流畅"当"传达到"（见 `ce02`、`p27`）。
- 六项齐全但核心不同：更糟的材料（见 `p04`、`p05`）。
- 把"发过了"当"沟通完成"（见 `ce10`）。
- 以为受众会原样接收：观众一定会改写，唯一能控制的是核心是否存活（见 `p28`）。

**容易混淆**
- ≠ 文案润色（改字句 vs 改结构）
- ≠ 评分表（分数不是目的，"手术级别"才是）
- 与单项能力的分界：体检只做定位，不在体检里直接大改——否则会同时动六项，失去可归因性。

**作者盲点（阶段 0 批判）**
六原则来自对"成功传播案例"的归纳，存在**幸存者偏差**：符合六项的材料不一定成功（渠道、时机、利益结构同样决定结果）。所以体检的结论应表述为"结构上更可能被记住"，而不是"一定会有效"。另外，本书几乎不讨论**渠道与重复**的作用——它默认表达是主要变量，这在信息过载的环境中偏乐观。

## 相关能力

- 依赖：无（可作为入口）
- 组合：`core-message`（体检第 2 步失败时直接转过去）、六张单项能力（按缺项分派）
- 对比：`counter-stickiness`（白纸 vs 已有成见）
