# 审片七问（打分表）

> 用法：逐项打分，**每项必须写出片中的镜号作为证据**，写不出即 0 分。不要凭印象给分。
> 打完按缺项数定返工级别。这张表的目的是让"感觉平"变成"第几镜缺什么"。

## 打分表

| # | 问 | 通过判据 | 证据（镜号） | 分 |
|---|---|---|---|---|
| 1 | **核心**：一句话能说清这条片子想让人记住什么吗 | 能说出，且这句话能否掉至少两个别的卖点 | | 0/1 |
| 2 | **钩子**：前 3 秒有没有打破观众的现状认知 | 第 1 镜含具体物件 + 动作 + 一句能听懂的话 | | 0/1 |
| 3 | **具体**：关键卖点有没有被画成一个可观察的动作或对比 | 至少 2 镜能被画成草图，且不是形容词 | | 0/1 |
| 4 | **可信**：有没有一个观众自己能验的东西 | 现场演示 / 极限测试 / 前后对照 / 可自己试的动作 | | 0/1 |
| 5 | **情感**：有没有一个具体的人让观众代入 | 一个人 + 一个时刻 + 一个后果（不是"很多家庭"） | | 0/1 |
| 6 | **结构**：障碍-动作-结果是否齐备且可照做 | "动作"那一段别人能照着做一遍 | | 0/1 |
| 7 | **转化**：有没有一个动作把观众推向下一步 | 能指出具体镜号与台词 | | 0/1 |

**第 7 问是补的。** 原书六问的验收标准是"记住并照做"，带货片要的是"下单"。缺这一问，会出现六项满分但不卖货的片子。

## 返工级别

| 缺项 | 手术级别 | 动作 |
|---|---|---|
| 0-1 项 | 局部修补 | 只补那一项，不动结构 |
| 2 项 | 结构调整 | 重排信息顺序、换开头 |
| ≥3 项 | **重拍** | 不要在台词上修，结构错了改字句是浪费 |

## 常见误判（打分时警惕）

- **把"流畅"当"过关"**：讲得顺、剪得滑不等于被记住。原书实验里，讲得最流畅的人内容几乎无人记得。
- **把"信息全"当"可信"**：塞参数不等于有凭证，观众没有自己验的入口。
- **把"煽情"当"情感"**：加 BGM 和旁白不产生代入，一个具体的人和时刻才产生。
- **把"有转化口播"当"有转化"**：说了"点击下方"不等于设计了一个决定理由。

## 复述测试（可选但推荐）

找 3 个没看过 brief 的人，正片播一遍，隔 1 小时问两句：

1. 这片子说了什么？
2. 你会不会买，为什么？

第 1 题答案偏离核心 → 缺 1、3；第 2 题答"再看看"且说不出理由 → 缺 5 或 7。这个测试比打分更准，但成本高，用于重点素材。
