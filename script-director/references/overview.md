## 1. 结构 (Structural)

### 类型

方法论 / 实操手册。属于"反向工程"式写作：先收集已经成功传播的样本（都市传说、谚语、寓言、获奖广告、优秀课堂、成功动员），再从中抽出共性，最后落成一份可勾选的检查表。

### 一句话主旨

让观点被听懂、被记住并真正改变行为（"黏性"）不是天赋而是设计——用「简、奇、具、信、情、事」六项检查表反复打磨一条核心信息，就能击穿"知识的诅咒"。

### 骨架 (主要论点及其关系)

1. **黏性可以反向工程，因此可以后天习得。** 天生有黏性的东西（偷肾传说、伊索寓言、跨 55 种语言的谚语）和精心设计的成功案例（电影院爆米花、诺德斯特龙、赛百味贾里德）共享同一批特征；1999 年以色列团队对 200 例获奖广告的研究显示 89% 可归入 6 套模板，而未获奖作品只有 2%；两小时模板培训就让新手原创性高出 50%。
2. **头号敌人不是表达技巧不足，而是"知识的诅咒"。** 击节者预估 50% 能被猜中，实际只有 2.5%。一旦知道，就无法还原"不知道"的心智状态。所有原则本质都是破解它的工具。
3. **做法分两步：先"找到核心"，再用六原则"转换核心"。** 简单（=核心+精炼）是唯一横跨两步的原则：它既决定"说什么"，也决定"说多长"。
4. **六原则各管一个沟通环节，构成一条链。** 意外→让人注意；具体→让人听懂记住；可信→让人愿意相信；情感→让人关心在乎；故事→让人起而行动；简单→决定说什么。
5. **原则必须服务于核心，否则降级为噪音。** 脱离核心的惊讶是噱头（狼群广告），脱离核心的故事只是好故事（克莱因的会议记录风波）。
6. **创造不如发掘。** 世界生产的好观点永远多于任何个体能创造的；缺的不是创意天才，是能识别故事的情节模板与"核心观点眼镜"。
7. **黏性一旦形成极难拔除，纠正错误观念只能"以黏制黏"。** 二战谣言管制、麦当劳蚯蚓谣言（"蚯蚓比牛肉贵"）、汽车可靠性大赛都证明：不要去证明谣言无根据，要用更黏的东西盖过它。

**论点之间的关系**: 1 是前提（可学），2 是障碍（为什么学不会），3 是总流程（递进），4 是并列的六个操作模块，5 是对 4 的约束（防误用），6 与 7 是两种元策略（分别对应"生产观点"与"对抗观点"），属递进后的横向扩展。

### 作者要解决的核心问题

为什么有些观点能流传并改变行为，有些转眼被忘？**没有预算、名气、权威的普通人，如何系统地让自己真正重要的想法产生黏性？**（前言明确排除了"靠重复"和"靠表达技巧"这两条常见答案。）

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 黏性 (stickiness) | 能被听懂、被记住、并形成持久影响（改变思想或行为） | 不等于"有趣"或"好听"。爆米花事件黏，狼群广告不黏——虽然两者都难忘 |
| 知识的诅咒 (curse of knowledge) | 一旦掌握某知识，就无法想象缺乏它的情形，因而无法与对方共享 | 不是"术语太多"，而是**心智状态的不可还原**；越专业越严重，且提醒自己"当年也很难"也无效 |
| 核心 (core) | 剥掉外壳后剩下的**唯一**优先项，即"指挥官意图" | 不是"简化/弱智化"。判断标准是能否在突发情况下指导决策；5 个"最重要"等于没有 |
| 基模 (schema) | 记忆中预存的一般属性集合，像一台"预测机器" | 不是"刻板印象"（贬义）；它是中性的认知基础设施，也是所有类比、意外、具体的操作对象 |
| 意外 (unexpected) | 破坏对方预测机器中**与核心相关**的那部分，并且"可以后测" | 不等于"新奇/吓人"。必须满足三条：破坏基模、对准核心、事后想得通 |
| 缺口 (knowledge gap) | 意识到"我不知道"所产生的痛感，是维持注意的引擎 | 不是"信息量不足"；恰恰要先点明对方缺什么。缺口太大时反而要先补背景 |
| 可后测 (postdictable) | 事前无论如何想不到，事后一听就懂 | 与"不可预测"并列成立才有效；只有不可预测 = 耍花招（"原来是一场梦"） |
| 具体 (concrete) | 能凭感官认知；特定的人在特定情境做特定的事 | 不是"细节多"。判断标准是能否想象出画面 / 能否据此行动 |
| 西纳特拉测试 | 单个案例本身就足以在任何领域建立可信（"在那儿能成，到哪儿都能成"） | 不是"举例说明"，而是**一次就够的资格证明**（运过《哈利·波特》+ 全国考卷 → 能运宝莱坞胶片） |
| 可检验性认证 | 把结论变成一个对方能亲手验证的挑战（"你自己去看"） | 不是"提供证据"，而是**交出裁判权**；代价是它同样能为假结论服务（斯纳普三 K 党谣言） |
| 语义夸张 (semantic stretch) | 高情感联想的词被反复挪用后贬值 | 不是"夸张修辞"，而是**词义的通货膨胀**："独特""体育精神""相对论"皆已破产 |
| 马斯洛地下室 | 误以为别人只被低层需求（钱、安全、地位）驱动，而自己住在顶层 | 书明确说金字塔的层次结构是错的：人同时追求所有需求；错的是**对他人动机的低估** |
| 身份认同决策 | 不问"对我有什么好处"，而问"我是谁 / 什么情况 / 像我这样的人该怎么做" | 与"理性权衡利弊"并列的第二套决策模式；能解释消防员为什么拒绝爆米花机 |
| 模拟 / 启发 | 故事的两大功能：提供行动脚本 / 提供行动能量 | "启发"不是"励志"，是具体的行动倾向（想更努力 / 想合作 / 想创新） |
| 三类情节 | 挑战（克服困难）、联系（跨越鸿沟）、创造（打破常规） | 不是文学分类，而是**三种不同的行动触发器**；选错情节会驱动错的行为 |
| 跳板故事 | 让人看见"现有问题可以怎样被解决"的故事，用于抵抗怀疑、制造代入 | 不是"案例分享"；关键在于它不主张结论，从而绕开听众心里的反驳声音 |
| 以黏制黏 | 不试图拔除错误观念，用黏性更强的观念盖过它 | 反直觉：证明"谣言无根据"是最弱的回应，因为那句话本身没有黏性 |

### 核心命题 (用自己的话)

1. 黏性是设计出来的，不是天生的；模板可以教，外行两小时就能显著提升。
2. 沟通失败的第一病因是知识的诅咒，不是表达技巧、不是受众不关心、更不是重复不够。
3. 简单 = 核心 + 精炼，两者缺一不可：只有精炼会变成无关口号，只有核心会变成冗长报告。
4. 精炼的真正目的不是"变短"，而是"在有限带宽里塞进更多"——靠调用对方已有的基模（柚子→西柚、公交车版《虎胆龙威》）。
5. 排序痛苦是必须付出的代价；不肯放弃"重要但非最重要"的内容，就会埋没导语。
6. 注意靠惊讶（破坏基模），维持注意靠缺口（先开再填）；惊讶必须可后测且对准核心。
7. 具体是唯一可靠的通用语言：新手需要它，专家协调也需要它（蓝图上越改越抽象，机器旁一摸就通）。
8. 人不是因为数字而相信，是因为**关联 + 可感知尺度 + 能亲手验证**而相信；生动的细节比成串统计更有说服力。
9. 情感不是煽情：一旦把人推入分析模式，同情心就会被削弱（罗基娅实验：加统计数据反而少捐）。
10. 让人关心有三条路：看见具体个人、诉诸自身利益（且要"确切"而非"巨大"）、诉诸身份认同。
11. 故事是心理飞行模拟器；**事件模拟（过程）优于结果模拟（幻想成功）**。
12. 故事要按想驱动的行为选情节，否则内容再好也驱动错方向。
13. 创造不如发掘：好故事每天都在产生，稀缺的是筛选器（"核心观点眼镜"）。
14. 观众一定会改写你的观点；判断成败的标准不是原话是否保留，而是核心是否存活。
15. 黏性无法拔除，只能覆盖；因此造黏性的人也要为"错误观念同样黏"负责。

### 论证链

作者的论证路径是**三重互锁**，不是单向推导：

- **归纳层**：以"天生有黏性"的语料（都市传说、寓言、谚语、阴谋论）为对照组，与"精心设计"的成功案例（CSPI 爆米花、诺德斯特龙、贾里德、真相广告）比对，抽出六项共同特征。
- **机制层**：为每条原则配一个心理学机制来解释"为什么有效"——基模与惊讶眉（意外）、洛温施坦缺口理论（好奇）、记忆的魔术贴与小钩子（具体）、生动细节实验与人性尺度（可信）、特蕾莎修女效应与身份认同决策（情感）、心理模拟实验（故事）。
- **验证层**：全书插入 9 个「创意诊断」before/after 对照，每个都给"简奇具信情事"六项打分卡，用同一把尺子证明改法有效（日晒、外援、筹款汇报、口服补液、鲨鱼、直觉缺陷、问题学生、代数需求）。
- **收束层**：结语给出"沟通五步 ↔ 六原则"映射，并承认最大漏洞——斯坦福演讲实验显示**演讲技巧与黏性几乎零相关**，63% 的人记得故事、只有 5% 记得数据。

## 3. 批判 (Critical) ★

### 作者的时代局限

- **2007 年的媒介结构**。核心假设是"你只有一次曝光机会"（西尔弗曼只能开一次记者会）。今天的注意力是算法分发、以秒计价、噱头通胀；缺口的半衰期被压缩，"可后测的惊讶"很容易在信息流里退化为"前 3 秒抓眼球"。
- **案例依赖美国大众媒体生态**（电视广告、报纸导语、脱口秀、公益广告）。报纸"倒金字塔"在推送标题时代已部分失效。
- **"89% 获奖广告落入 6 类模板"的证据强度被高估**。样本是获奖作品，获奖本身要求可被评委快速理解，存在选择偏差；且这是 1999 年对印刷/影视广告的研究，不能直接外推到长内容与交互界面。
- **引用的心理学研究未标注效应量，部分处在后来的可重复性争议区**（生动细节对判决的影响、缺口理论的操作化、心理模拟的收益"相当于真实练习的 2/3"）。

### 作者的立场盲点

- **只写"说服"，不写"该不该说服"**。两位作者是商学院教授与出版人，所有案例都是"我想让你记住/相信/行动"，几乎没有讨论被说服者的知情同意、拒绝权、以及"沉默的大多数"。这使得本书极易被读成操纵手册。
- **成功者偏差**。案例全是"黏住了的"，没有系统统计"同样符合六原则但失败了"的样本，也没有给出各原则的**相对权重**——实际上无法判断"哪一条最关键"。
- **权力不对称被略过**。黏性是放大器，不解决"你有没有资格被听见"。一个没有席位的实习生的黏性提案，和 CEO 的黏性提案，命运完全不同；书中把这个差异归入了"肯尼迪不是典型"的一句自嘲。
- **美式乐观**。"普通人也能做到"忽略了资源、渠道、语言、文化语境的现实约束；对非英语、非西方受众，"高概念（X 版的 Y）"依赖的共享片库可能根本不存在。

### 未被证明的假设

1. **假设"黏性 = 好"**。书自己前半本就证明了黏性对错误观念同样有效（偷肾、毒糖果、大脑只用 10%、肯德基炸老鼠），却始终没有给出"如何判断一条黏性信息该不该被传播"的标准。
2. **假设"被记住就会改变行为"**。斯坦福演讲实验只测了"记得"，贾里德与真相广告只给了相关性（同期还有烟草税上调、减肥许愿潮等混淆变量）。
3. **假设"观众改写后核心还在就没问题"** ——但由谁判定核心？作者把裁判权交回了创造者自己（迪罗谢最终接受了"好人总是屈居末座"）。
4. **假设"具体总是优于抽象"**。书自己承认原子行星模型不准确，主张"够用优先于正确"；但没有给出**何时必须牺牲可理解性去换准确性**的判据（在医疗、法律、安全领域这是要命的）。
5. **假设"知识缺口总是好的"**。缺口会制造焦虑，也会制造阴谋论的温床（书中自己提到阴谋论正是为了消化意外而生）。

### 最强反对意见

> **"这是一本放大器手册，不是判断力手册。"** 它把传播失败几乎全部归因于信息设计，而真实世界里大多数重要观点死于没有渠道、没有信任、没有利益相关方——你把内容打磨得再黏，也不会让一个没有权力的人说服董事会。更严重的是，它的方法对最坏的主张同样有效：越是高明的黏性技术，越让错误观念难以纠正（作者自己用"以黏制黏"承认了这一点）。所以这本书真正需要的，是一份前置的伦理与适用性检查——而它没有写。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**：每条 skill 的 B 段必须包含"黏性 ≠ 正确性"与"放大器不解决权限"这两条。

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容

- [x] 黏性体检：六项检查表 + 「症状 → 解方」映射（结语 + 各章创意诊断打分卡）
- [x] 找核心：指挥官意图两问 + 挖出导语 + 强迫排序（第 1 章前半）
- [x] 精炼与打包：谚语化、视觉谚语、基模/高概念/生成性类比（第 1 章后半）
- [x] 意外与缺口：破坏基模、可后测、好奇心缺口、背景铺垫（第 2 章）
- [x] 具体化：感官化、具体道具/共同领地、命名与原型人物、魔术贴钩子（第 3 章）
- [x] 可信度工程：六种可信源选择、人性尺度、西纳特拉测试、可检验性认证（第 4 章）
- [x] 情感与身份：个体化、抗分析、三个为什么、跳出马斯洛地下室、身份认同（第 5 章）
- [x] 故事设计与发掘：模拟/启发、三类情节、跳板故事、伯乐之眼（第 6 章）
- [x] 黏性战略：把组织战略变成可执行的共同语言（附录 1-1）
- [x] 以黏制黏：纠正错误观念（附录 1-3）
- [ ] 黏性教学（附录 1-2）：是六原则的教学场景应用，作为案例与示例保留，不独立成 skill（否则与六个原则 skill 高度重复）

### 不适合 skill 化的内容

- 都市传说/阴谋论的史料与考据（偷肾、毒糖果、食人香蕉的流传史）
- 各章名人轶事与作者个人经历（希思兄弟的写作缘起、巴菲特讲布卢姆金的故事）
- 大量脚注文献（作为 source_evidence 保留，不进入能力卡正文）
- "创意诊断"的具体文本改写（作为案例 → A1 段的素材，不作为可执行步骤）

### 预估 skill 数量

**约 7–9 个**（含 1 个来源路由入口）。最终由阶段 1.5 三重验证 + 阶段 1.6 晋级门决定，这里只是粗估。

### 优先级排序 (按"最能赋能普通人"的角度)

1. **黏性体检**（诊断入口：任何文案/方案/汇报先过一遍六项打分）
2. **找核心**（最高杠杆：核心错了，后面五项全白做）
3. **具体化**（作者自己说这是六项里最容易做到、也最有效的一项）
4. **意外与缺口**（决定对方是否开始听、是否继续听）
5. **情感与身份**（"相信但不行动"是最常见的失败）
6. **故事设计与发掘**（行动力的来源，且可复用真实素材而非编造）
