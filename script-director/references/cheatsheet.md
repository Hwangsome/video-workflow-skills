# 决策规则速查 — 让创意更有黏性：创意直抵人心的六条路径

| 能力 | 一句话规则 |
|---|---|
| 找核心 | 核心不是摘要，是"只能保住一句时保哪句"，并且它必须能否决一个具体提案。 |
| 黏性体检 | 六项逐条找证据打分，缺三项以上就重写，最后用隔日复述测试验收。 |
| 具体化 | 具体不是细节多，是能被感官或动作认领——画不出来就还没具体。 |
| 意外与好奇心缺口 | 先说出他现在的解释，再指出这个解释算不平的那个数——缺口是这么开的。 |
| 可信凭证 | 可信不是"我可靠"，是"这个结论你能自己验"——把裁判权交出去。 |
| 唤起感受 | 先把他从"一群人"变成"一个人"，再问"像我这样的人会不会做"。 |
| 故事力 | 先定要驱动的行为，再选情节（挑战/联系/创造），补齐障碍-动作-结果，然后闭嘴不要总结。 |
| 以黏制黏 | 黏性拔不掉只能覆盖——新东西必须比旧的更有画面、更有情节、更可验证。 |
| 用旧概念装新概念 | 类比的好坏不看像不像，看它能不能长出新的、正确的结论。 |
| 模拟体验 | 只想象成功会降低行动率——把场景切成节点，逐节点预演"他若说 X 我就做 Y"。 |
| 共同语汇 | 战略压成 3-5 个能用来否决提案的形容词，并且让下级能用它反驳上级。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
