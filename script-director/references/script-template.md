# 分镜脚本模板

> 用法：先填表头四项（缺一不要往下写），再逐镜填主体。最后一列"它完成什么"必须填——填不出来的镜头就是可删的镜头。

## 表头

| 项 | 内容 |
|---|---|
| 给谁看 | 一个人，不是人群标签（例：租房、独居、每周打扫一次卫生的 26 岁上班族） |
| 在哪看 | 信息流 / 搜索 / 直播间切片（决定第 1 秒能不能有铺垫） |
| 看完做什么 | 下单 / 收藏 / 搜品牌词（只能选一个） |
| 不能说什么 | 资质、极限词、平台禁词、竞品贬损（须书面确认） |
| 核心一句 | 只能一句，且能举出它否掉的两个卖点 |
| 钩子一句 | 前 3 秒那句，须含具体物件 + 动作 |
| 转化三个数 | 数量 / 单价 / 使用时长（至少一个） |

## 分镜表

| 镜号 | 时长 | 景别 | 画面（能被拍出来的描述） | 口播 | 字幕 | 道具 | 它完成什么 |
|---|---|---|---|---|---|---|---|
| 1 | 0-3s | 特写 | 手从底座提起旧刷，底座内一汪浑水 | 你家马桶刷的底座里，现在还有水吗 | 底座里的水 | 旧刷+底座 | 钩子：点破现状 |
| 2 | 3-6s | 特写/近景 | 那汪水倒进透明玻璃杯，对灯 | 这水，是你上次刷完留下的 | — | 透明杯 | 钩子：把问题变可见 |
| 3 | 6-9s | 中景 | 掰下新刷头，丢进马桶 | 所以我换了这个，刷完就扔 | 刷完就扔 | 产品 | 核心：给出解法 |
| 4 | 9-17s | 近景 | 夹持刷头刷内壁死角，泡沫白转灰 | 边角它自己带清洁剂，你不用挤 | — | 产品 | 演示：动作可照做 |

## 自检（贴在分镜表下方）

- [ ] 第 1 镜含"具体物件 + 动作 + 一句能听懂的话"
- [ ] 全片信息点 ≤ 4 个（核心 1 + 支撑 2 + 转化 1）
- [ ] 每一镜的"它完成什么"都填了，且不重复
- [ ] 至少有一个镜头能让观众自己试一遍
- [ ] 演示镜头一镜到底，或同机位同时间段内切
- [ ] 结尾有数量 / 单价 / 时长中的至少一个具体数
- [ ] 没有极限词与未获资质的功效表述
- [ ] 全片时长与镜数匹配：15-45 秒 → 6-10 镜

## B-roll 与备用镜

| 备用镜 | 用途 | 触发条件 |
|---|---|---|
| 旧刷毛根发黑特写 | 加强"泡在自己刷过的东西里" | 第 2 镜数据差时前置 |
| 刷头在水里化开的慢镜 | 加强"冲走不堵" | 评论区质疑堵塞时 |
| 手指按压刷头回弹 | 加强"不散" | 出现"智商税"评论时 |

> 备用镜不占正片时长，用于二次剪辑与差评应对。
