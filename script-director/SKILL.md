# 编导脚本流水线

## 这个技能是什么

一条**从 brief 到成片的流水线**，用来解决编导最常卡的三件事：卖点太多不敢砍、卖点说不成画面、审片只能说"感觉平"。

它借用《让创意更有黏性》的六条原则作为**判断依据**，但组织方式是按**你的工作顺序**，不是按原则分类。你不必知道"意外原则"，只需要知道第 3 步该做什么。

## 这个技能不是什么

- 不是镜头语言手册：景别、运镜、灯光、构图、演员调度不在范围内。
- 不是投放工具：出价、人群包、素材 AB、GMV 归因不在范围内。
- 不是剧本医生：15-90 秒带货/演示片的结构和 90 分钟影视剧本是两套东西。剧情类短片、品牌微电影、系列短剧的人物弧线与三幕结构，用 `save-the-cat-screenwriting`，不要用本技能的带货流水线。
- 不会替你定卖点：它只提供取舍的判据，卖点来自产品与用户。

## 八步流水线

### S1 接 brief：先把四件事问清

**做什么**：在写任何字之前，确认 ① 给谁看（一个具体的人，不是"25-45 岁女性"）② 在哪看（信息流/搜索/直播间切片，决定前 1 秒能不能有铺垫）③ 看完要做什么（下单/收藏/搜索品牌词）④ 不能说什么（资质、极限词、平台禁词）。

**完成标准**：四件事各有一句话答案，且第 ④ 项已和白纸黑字确认。这一项没确认就往下走，是后面全部返工的源头。

**判停**：若 ③ 说不清（"就想曝光一下"），先回到 brief 方确认，不要用"提高品牌好感"糊过去。

### S2 定核心：从卖点清单砍到一句

**做什么**：让 brief 方先给全部卖点（通常 6-10 个），然后逐条问：**如果没有它，别的那句还成立吗**？能删的删掉，剩一句。再用三关检验：能否掉一个别的卖点、竞品说不了这句话吗、拍摄现场能一句话说清吗。

**完成标准**：一句话，且你能举出它否掉的至少两个卖点。

**读**：`references/capabilities/core-message.md`

**判停**：若剩两句且互不覆盖，说明产品有两个不同人群——这是要拍两条片子，不是一条片子里说两件事。

### S3 定钩子：前 3 秒

**做什么**：写出目标观众此刻的解释（"马桶刷不就是刷完冲一下放回去"），再找到这个解释算不平的具体事实（"底座里那汪水是你上次刷的东西"）。

**完成标准**：第 1 镜同时具备三样——一个具体物件、一个动作、一句能听懂的话。三者缺一，前 3 秒就在耗流量。

**读**：`references/capabilities/curiosity-gap.md`

**判停**：若钩子必须靠旁白解释三句才成立，说明缺口开太大，换一个更贴近他日常的入口。

### S4 排结构：障碍-动作-结果

**做什么**：选情节类型——带货片九成用**创造情节**（老问题有新解法），攻坚类卖点用**挑战情节**（极限场景）。然后补齐三段：障碍（越具体越可信）、动作（观众能照做的那一步）、结果（可见，不要形容词）。

**完成标准**：三段齐备，且"动作"这一段能被别人照着做一遍。

**读**：`references/capabilities/story-power.md`

**判停**：若三段里"动作"写不出来，说明这个卖点不可拍，回到 S2 换卖点。

### S5 写分镜：每个卖点必须变成能被画出来的东西

**做什么**：逐镜填表（用 `references/script-template.md`）。每个信息点过一道判据：**这句话能画出来吗**？画不出来就是形容词，必须换成一个可观察的动作或对比。同时给关键镜设计"能自己验"的动作——现场演示、极限测试、可对照的前后对比。

**完成标准**：任意挑一镜，把画面描述给别人，他能画出接近的分镜草图；且全片至少有一个"观众自己也能试"的动作。

**读**：`references/capabilities/concretize.md`、`references/capabilities/credible-evidence.md`

**判停**：若某个卖点连续三镜都只能靠口播说，删掉它——说不成画面的卖点在短视频里等于不存在。

### S6 补转化：书里没有的第七问

**做什么**：检查片子里有没有一个动作把观众推向下一步——指向购物车、说出搜索词、给出数量/价格/时长的具体数、制造"现在决定"的理由。

**完成标准**：能指出具体某一镜、具体一句台词完成了这件事。指不出来就是没有。

**为什么单列**：原书六问的验收标准是"记住并照做"，电商要的是"下单"。一条让人记住但不促单的片子，六问可能满分。这一问是补它的盲区。

### S7 审片：七问打分

**做什么**：用 `references/review-scorecard.md` 逐项打分，每项必须指出片中的具体镜号作为证据，指不出即 0 分。按缺项数量定返工级别。

**完成标准**：产出一张带镜号证据的评分表，而不是一句"感觉还行"。

**读**：`references/capabilities/stickiness-audit.md`

### S8 交付：输出资产

**做什么**：审片通过后，把策划沉淀成两个文件，写入**当前工作目录的 `outputs/`**（不存在则创建）：

1. `脚本-<产品名>-<YYYYMMDD>.md` — 完整策划文档，结构照 `references/script-template.md`：表头（给谁看/在哪看/看完做什么/不能说什么 + 核心一句/钩子一句/转化三个数）+ 分镜表 + 自检清单 + 备用镜。
2. `脚本-<产品名>-<YYYYMMDD>.html` — 单文件 HTML，从 `references/html-skeleton.html` 复制后填充。硬性要求：
   - **自包含**：零外部资源（无 CDN、无网络字体、无外链图片），发到微信/钉钉打开即读
   - **浅色、可打印**：A4 下分镜卡片不跨页断裂（`break-inside: avoid`）
   - **卡片式分镜**：每镜一张卡，镜号+时长置顶醒目，画面描述与口播分开排
   - 顶部必须有"核心一句"和"转化三个数"——拍摄团队最先看的两行

**完成标准**：两个文件都生成；md 中"它完成什么"列无空格；html 在无网环境可正常打开。

**判停**：只输出对话、不落盘文件，视为本步未完成。策划不落盘等于没做——聊天记录里的分镜表发不到拍摄群。

### S9 上线后：差评与黑稿

**做什么**：评论区出现"一次性就是智商税""不耐用"这类成见时，不去评论里辩论，补一个动作镜头盖过去（用力蹭、踩、拉拽），或在下一条片子的第 5 镜加进去。

**完成标准**：新素材里有一个比负面说法更有画面、更可验证的镜头。

**读**：`references/capabilities/counter-stickiness.md`

## 编导判据（经验值，非原书内容）

以下是短视频作业的通行经验，用来给上面七步提供量化抓手。**它们不是这本书的结论**，遇到平台或品类差异请以实际数据为准。

- **前 3 秒三件套**：具体物件 + 一个动作 + 一句能听懂的话。缺一样就在耗流量。
- **15-45 秒带货片**：6-10 镜，平均 4-6 秒一镜；信息点不超过 4 个（核心 1 个 + 支撑 2 个 + 转化 1 个）。
- **演示镜头一镜到底**：切过的演示等于可疑的演示。要切就在同一个机位、同一段时间内切。
- **画面优先于口播**：能被看见的不要用说的。口播只承担三件事——点破现状、给出结论、说出转化动作。
- **结尾三个具体数**：数量（一盒 30 个）、单价、或使用时长。三者至少给一个，"很划算"不算。
- **合规红线**：杀菌率、除菌率、"最""第一""国家级"需要资质或禁用；演示效果不能靠剪辑造假。

## 边界与判停

- **不要用**：剧情类短片 / 品牌微电影 / 系列短剧（有人物转变弧线、靠故事而非卖点驱动）——那是 `save-the-cat-screenwriting` 的活（五问校直脊柱、五要点结局、三病症）；本技能处理的是卖点驱动的演示片。
- **不要用**：纯文字材料（汇报、方案、文章）——那是 `made-to-stick` / `stickiness-audit` 的活，用本技能会把文字稿写成拍摄稿。
- **不要用**：需要精确传达参数、用法、禁忌的说明书式内容——六原则会为了黏性牺牲完整性。
- **停止条件**：七问里缺三项以上，停止改台词，直接告知需要重拍结构；改字句救不了一条结构错的片子。
- **停止条件**：brief 的"不能说什么"未确认时，停止输出任何含功效表述的台词。
- **停止条件**：用户要的是投放策略、出价、素材 AB——明确说明超出范围，不要用"内容优化"代替投放判断。

## 加载规则

1. 先按八步走，每步只读当前步指定的那张卡，不要一次读全部。
2. 需要原文依据、反例、术语澄清时，读 `references/overview.md`、`references/glossary.md`、`references/cheatsheet.md`。
3. S8 交付时：md 照 `references/script-template.md` 的结构，html 从 `references/html-skeleton.html` 复制填充，两者都要落盘到 `outputs/`。
4. 八步都走完仍不满意，再回头读 `references/capabilities/emotional-appeal.md`（多半是缺"具体的人"）或 `references/capabilities/high-concept-analogy.md`（多半是品类太新，观众没有接收框架）。
