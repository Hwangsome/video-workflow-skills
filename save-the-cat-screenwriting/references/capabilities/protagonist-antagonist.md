## R — Reading(原文)

> "理想的主角是在那种情景下带来最大冲突、最长情感历程及大家都支持的原始目标的人。生存、饥饿、性、保护所爱之人、死亡恐惧都会吸引我们……"——第一本 第三章「主角是谁」

> "我们必须让困难稍大于主角的承受能力。让坏蛋变得更坏自然而然地会让主角更加强大。"——第一本 第六章

出处:第一本 L1333–1597、L2643–2657;第三本 主角判定补全 L17940–17960。

## I — Interpretation(自述)

这套设计法把"角色"当成为故事服务的零件,判据是**可比较的**,不是"这个人有没有魅力"。

**主角的四个判据**(同一情境下,最符合的人才是主角):
1. 与目标观众最相像(观众有代入通道)。
2. 能带来最大冲突(他的存在让对手最难受)。
3. 能走最远的情感历程(从最差到最好,或从最好到最差)。
4. 最不想改变却最需要改变。

配套三道闸门:
- **原始性**:主角的目标必须能还原到生存 / 饥饿 / 性 / 保护所爱 / 恐惧死亡 中的至少一项。检验法:山顶洞人看得懂吗?看不懂就是动机太"文明"。
- **主动性**:主角自己决定进入新世界,不能被骗进去、漂进去;主角不问东问西,是别人围着主角要答案。
- **形容词**:一句话里必须各有一个形容词描述主角与坏蛋("畏首畏尾的老师""滥用武力的警察"),形容词缺失 = 人物没定型。

**坏蛋三规则**:
1. **坏到极致**——主角看起来不够英雄,往往不是主角的问题,是坏蛋太弱。
2. **稍强一点点**——强到"看似不可能",但不能强到不可战胜;他的优势来自"不择手段"。
3. **镜像**——主角与坏蛋常是同一个欲望的光明面与黑暗面,争的是同一样东西(所以《风月俏佳人》里坏蛋是那个只想占有的合伙人)。

另加一条工业现实:**写原型,不写明星**。主角要能被 5 个演员演,否则剧本会因"只有一个人能演"而睡抽屉。

## A1 — Past Application(书中案例)

- **《三年级》**(作者卖给环球的剧本):大前提是"成年人被判回三年级重读"。作者的选择依据正是四判据——最需要这门课的是"表面成功、内里没长大"的人,于是主角定为给儿童设计暴力游戏的成功商人:冲突最大、旅程最远、观众最支持。
- **《鸡鹰降落》**(作者与谢尔登合写,未卖出):总统单枪匹马抓本·拉登的喜剧,题材好、故事好,但主角几乎只有两个人能演,剧本因此搁浅。作者用它证明"为明星写角色"的成本。
- **《梦幻汽车》**:德罗宁传记片,原型人物有争议、不可爱。作者的解法是换主角——用跟随他多年、逐渐失望的下属做视角人物,让观众通过"局内人"进入。
- **《低俗小说》**:两个吸毒杀手本不讨喜,塔伦蒂诺让他们有趣、天真(讨论麦当劳汉堡的法语叫法),并让他们老板比他们更可怕——"让对手更坏"这条救猫咪变体。

## A2 — Future Trigger(触发条件)

**用户情境**
1. 故事/案例/品牌故事里"不知道谁该是主角"。
2. 主角写了但"不吸引人""没存在感""像旁观者"。
3. 反派/竞品/对手写得没威胁,导致主角的胜利没有价值。
4. 要给人物写档案,但不想写成履历表。

**语言信号**
- "谁应该是主角 / 主角选谁好 / 这个人物立不住"
- "主角太被动 / 主角不讨喜 / 反派太弱"
- "protagonist / antagonist / 人物小传 / 角色设定"
- "怎么让读者喜欢这个角色"

**与相邻能力的区分(定稿)**
- 用户在问"整个故事该讲什么" → `spine-five-questions`(第 1 问才是主角)。
- 用户要判断"人物说话是否可区分" → `dialogue-detection`。
- 用户要判断"这个点子能不能成立" → `bad-idea-warnings` 或 `logline-validation`。

## E — Execution(可执行步骤)

1. **列 3 个候选主角**,逐个用四判据打分(相像度/冲突量/历程长度/抗拒改变程度),选总分最高者。完成标准:能说出"为什么不是另外两个"。
2. **写两个形容词**。一句"一个___的___,必须对抗一个___的___"。完成标准:两个形容词都是性格/处境类,不是职业类("警察"不是形容词)。
3. **原始性检验**。把主角目标追溯到五类原始驱动之一。完成标准:能用一句"他其实是在争夺___"说出来;说不出来就重设目标。
4. **主动性审计**。检查三处:他是否自己决定进入第二幕?线索是他找到的还是别人递给他的?他的台词里问号多不多?完成标准:三处都能指出具体场景。
5. **坏蛋三查**。坏蛋是否足够坏(有没有做一件让观众恨的事)?是否只稍强于主角?是否与主角争同一样东西?完成标准:三条各有一句证据。
6. **选角弹性检查**。列出至少 3 个能演主角的演员类型。完成标准:如果只能想到 1 个,改写主角的年龄/职业/性别设定。
7. **输出**:主角一句话(含形容词)+ 四判据打分表 + 原始目标溯源 + 坏蛋三查结论 + 主动性证据(3 个场景)。

## B — Boundary(边界)

- **多主角/群像作品**:需先选"脊柱切入点角色"(《撞车》用唐·钱德尔,《巴别塔》用布拉德·皮特),不是取消主角。
- **传记片/真实事件**:真实人物常常不可爱或不道德,允许"善意篡改"或换视角人物,但必须让观众能理解他。
- **原型二分有过时之处**:"意气风发的小伙子/可爱的好女孩"带有 2000 年代的性别刻板印象,现代项目应替换为更中性的原型描述。
- **不需要对手的故事**:纯内心成长/状态型作品可能没有具体坏蛋,此时第 5 步跳过,改用"内在缺陷"作为对抗力量。

## 相关能力

- **组合** `spine-five-questions`:那张卡的第 1 问直接调用本卡的判据;本卡也可单独用于"人物立不住"的局部修复。
- **组合** `golden-rules`:救猫咪正是"主角认同"的检测项,两条常一起用。
- **组合** `dialogue-detection`:人物定型之后,语言特征才落得下去。
