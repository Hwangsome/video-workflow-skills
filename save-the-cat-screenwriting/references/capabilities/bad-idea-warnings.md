## R — Reading(原文)

> "关于这可能是很糟糕的一个想法的7条'警示':1.不敢告诉任何人。2.害怕别人偷去了这个想法……5.缺少基本的逻辑点……6.有很多很棒的'画面',但是没有故事。"——第三本 第一章「逊毙了的想法!」

> "如果一味保密,不让别人参与这个过程……我最终就毁了这个灵感。"——第三本 第一章

出处:第三本 L16077–16130;课堂扩展 L17101–17116。

## I — Interpretation(自述)

核心洞察是反直觉的:**当你死死护着一个点子不让人知道时,你护住的往往不是一个宝藏,而是一个缺陷**。保密不是因为点子太好,而是因为潜意识里知道它经不起追问。

七条警示(命中任意一条,该点子就需要外部验证):
1. 不敢告诉任何人。
2. 害怕别人偷走它。
3. 担心说出来"魔力"就散了。
4. 担心不赶紧写下来它就跑了。
5. 缺少基本的逻辑点(作者自承忽略的那条,也是最致命的一条)。
6. 有很多很棒的"画面",但没有故事。
7. 没有做过检索,不知道别人是否写过。

三条课堂常见的同类错误(第三本第二章):
- **"这件事就发生在我身上!"**——把个人经历当故事。真实经历通常不构成故事结构;当"真实"与"故事"冲突时,故事优先。
- **抄袭而不自知**:看到一部冷门片,原样复述。
- **幻想世界无故事**:设定越精致,越容易掩盖"没有故事"这件事。

处置逻辑:点子不怕被讲,怕的是没人愿意听第二遍。所以验证方式只有一个——**讲出去,看反应**。若讲出去没人追问,问题不在保密,在点子。

## A1 — Past Application(书中案例)

- **《精灵》(Twinkle)**:作者自认的失败案例。圣诞老人穿过魔法机器变成汤姆·汉克斯 48 小时,与女主恋爱,再变回 600 岁的胖老人。他一直保密、不敢讲,直到经理人问出两个问题("克劳斯小姐躺在墓地里不奇怪吗?""变回来之后女主怎么办?")——七条警示他中了六条,尤其第 5 条(逻辑点缺失)。剧本最终锁进抽屉。
- **迪斯尼编剧朋友**:作者随口问"在忙什么",对方说"坐下",然后讲了 20 分钟"暴风雨的黑暗夜晚"式的场景,却说不清故事是什么。写了 50 页后自己锁进抽屉,回头质问作者"你当时为什么不阻止我"。
- **《左翼分子》**(与霍华德合写):主角既是左翼分子、又是左撇子、又是拳击手——糖太多了,创意自我抵消。属第 6 条变体:元素很多,故事没有。

## A2 — Future Trigger(触发条件)

**用户情境**
1. 有个想法"特别好",但一直没动手、也没跟人说过。
2. 用户反复强调"别外传""这个不能讲"。
3. 用户描述创意时全是画面/氛围/名场面,说不出人物与冲突。
4. 用户问"这个点子会不会被人抄走"。

**语言信号**
- "这个想法我谁都没告诉 / 说了怕被抄"
- "我有很多很酷的画面,但还没想好故事"
- "这个点子值不值得做 / 要不要开始写"
- "idea validation / 创意验证 / 点子好不好"

**与相邻能力的区分(定稿)**
- 点子能讲清但**不够吸引** → `logline-validation`(四要素)。
- 点子已经开写、**结构有问题** → `three-structural-ailments` / `story-diagnosis-checklist`。
- 本卡专门处理"**还没验证就开始护着**"这个前置状态。

## E — Execution(可执行步骤)

1. **七条自评**。逐条打勾。完成标准:给出命中条数,并明确是否命中第 5、6 条(这两条是硬伤)。
2. **硬伤判定**。若命中 5 或 6:要求用户用三句话说清"谁、要什么、什么挡着他"。说不清 → 判定"还没有故事",进入第 3 步;说得清 → 进入第 4 步。
3. **拆画面**。把用户热衷的画面/设定列出来,逐个问"这个画面改变了什么处境?"答不出的,标为"可保留的装饰"(最多留 2 个)。
4. **检索**。用一句话去搜同题材作品,列出 3 个最像的。完成标准:能说出"我和它们的差别在哪一点"。
5. **外部测试**。今天找 3 个非同行讲,记录:是否追问、追问了什么、是否替你补完。完成标准:至少 1 人主动追问细节。
6. **输出**:七条自查表 + 硬伤判定 + 装饰清单 + 3 个对标 + 测试记录 + 结论(继续/改造/放弃)。

## B — Boundary(边界)

- **不否定合理保密**:未申请的专利、商业机密、涉及他人隐私的素材,不应拿去公开测试。可改用脱敏版(只讲问题与受益)。
- **不适用于已进入执行期的项目**:已经在拍的片子不需要"该不该做"的验证,此时用 `story-diagnosis-checklist`。
- **课堂三条错误的适用面有限**:"真实经历不能直接当故事"是强判断,回忆录/纪实类作品需要的是另一套标准。
- **别把它变成否定工具**:作者的原意是"去验证",不是"你不行"。建议时保持"这条警示指向的是验证动作"。

## 相关能力

- **对比** `logline-validation`:本卡负责"该不该讲出来",那张负责"讲出来之后够不够吸引"。
- **组合** `three-structural-ailments`:点子过关后,第一版结构最常见的病就是枝蔓与半步缓行。
