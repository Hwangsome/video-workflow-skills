## R — Reading(原文)

> "这个'五要点风暴袭击城堡',在每个故事中都以某种形式或风格存在!这就是'直面恐惧'的部分,是最终的考验,用以证明主角到底有没有认真地学到真谛!"——第三本 第三章「才思枯竭、无路可走」

> "高塔意外,表明我们不仅对自己的计划过于自信,而且过分自信本身就是问题之一!……完美计划原来是恶人们设置的陷阱。"——第三本 第三章

出处:第三本 L17589–17738。

## I — Interpretation(自述)

多数第三幕的问题是"一路平推":主角带人冲进去、打一架、赢了。五要点结局要求在这条直线中间**强制插入一次失败**,并把"新计划"建立在这个失败上。

五步:

1. **召集团队**:主角主动跨进第三幕,和解、找人、备工具、定计划。功能:把前两幕积累的资源一次性兑现。
2. **执行计划**:真的开打/真的实施,团队像上了油的机器,看上去一切顺利(此时常牺牲一个配角来抬高风险)。
3. **高塔意外**:到了地方发现"公主不在"——计划是敌人设的陷阱,内部可能还有叛徒,主角的所有准备全部作废。功能:让"过度自信"本身成为问题。
4. **深入挖掘**:常规手段全部无效,主角必须做一件"开头绝不会做的事",依据不再是技巧而是信念/内在力量。
5. **新计划**:答案来自主角坚信的那个说不清的东西——最后一搏,赢了,同时把开场与中点的伏笔一次性收掉。

关键判断:**第 3 步决定第三幕是不是"打一遍就完了"**。没有高塔意外,主角的成长就没有被验证;有了它,前面的所有 B 故事教育才有落点。

同一结构在进攻(拯救大兵瑞恩)、防守(异形/活死人)、逃离(逃离德黑兰)三种形态下都成立。

## A1 — Past Application(书中案例)

- **《魔法奇缘》变体**:高塔里的"公主"自己已经能打——作者用它说明五要点不是死板模板,"公主可以自己救自己",第 3 步的意外可以来自主角之外的人。
- **《角斗士》**:叛徒在高塔意外处暴露,完美计划原来是陷阱,由此进入"深入挖掘"——马克西姆斯放弃"用规则赢"的幻想,改用"在竞技场里让人民看见"的新计划。
- **《黑客帝国》召集团队段**:装枪、上弹、走进大楼,是"召集团队 + 执行计划"的标准示范。
- **作者自述的批评**:他会因此被说"太公式化",他的回应是"魔力和公式化完全不相关"——五要点保证的是结构落差,不是内容雷同。

## A2 — Future Trigger(触发条件)

**用户情境**
1. 第三幕/结尾/最后一章/路演收尾已经写了,但"平""像流程汇报"。
2. 需要一个让主角"真的学到了"的验证点。
3. 提案/演讲的收尾需要有反转和记忆点。
4. 系列内容的最终集/年度总结需要收得有力。

**语言信号**
- "结尾怎么写才不平 / 高潮怎么设计 / 最后一章怎么收"
- "第三幕太弱 / 结局没劲 / 打一架就完了"
- "finale / climax / 收尾"
- "路演最后怎么讲 / 提案怎么收"

**与相邻能力的区分(定稿)**
- 需要**判断整条结构哪一格弱** → `beat-sheet-bs2` / `story-diagnosis-checklist`;本卡只负责第三幕内部。
- 需要**制造加速感**(越往后越紧)→ `escalation-color-wheel`。
- 需要**给结局定主题落点** → `spine-five-questions` 第 5 问。

## E — Execution(可执行步骤)

1. **写出现有第三幕的三句话**(进去—打—赢)。完成标准:能明确标出"哪里本该有失败却没有"。
2. **插入高塔意外**。设计"到了发现不在/计划是陷阱/内部有叛徒"三类之一。完成标准:这个意外必须让前面两幕的某个"准备"失效,而不只是"多一个敌人"。
3. **写深入挖掘**。让主角做一件"开场时绝对不会做"的事,并说清依据是哪个 B 故事教给他的。完成标准:能引用 B 故事里的一个具体场景作为来源。
4. **写新计划**。新计划必须用到"高塔意外"暴露出的信息(否则意外白设计了)。完成标准:能指出新计划利用了意外的哪一点。
5. **收伏笔**。列出开场/中点埋的 3 个种子,逐个在结局收到。完成标准:3 个都有回收动作。
6. **输出**:五段式第三幕大纲(每段 2–3 句)+ 意外类型 + 深挖依据(引用 B 故事场景)+ 新计划对意外的利用点 + 伏笔回收表。

## B — Boundary(边界)

- **不适用于反高潮结尾**:作者电影、文学性结尾常刻意"不平",此时五要点会破坏意图。
- **不适合没有对手的故事**:纯内心/状态型作品没有"城堡",强行设计高塔意外会显得做作。
- **警惕"公式化"**:五要点是落差模具,内容必须来自本项目特有的 B 故事;若五步都能用任意类型片的常见桥段填满,说明还没写到位。
- **与"最后一分钟营救"的区别**:那是节奏技巧,五要点要求的是"计划失效"这一结构事实。

## 相关能力

- **依赖** `spine-five-questions`:第四步"深入挖掘"的依据必须来自 B 故事教给主角的东西。
