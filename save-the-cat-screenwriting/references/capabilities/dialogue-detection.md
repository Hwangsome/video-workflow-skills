## R — Reading(原文)

> "'说情节'……人物走到画面里说'喂,要知道你是我的姐姐!'……很糟糕!……观众都讨厌这样。"——第一本 第六章「影片出了什么问题」

> "盖住说话者的名字,然后来来回回读若干人物的台词。在不看名字的前提下,你能分辨出说话者是谁吗?"——第一本 第六章

出处:第一本 L2629–2641、L2707–2729;人物可辨识度姊妹技法"瘸腿和眼罩" L2745–2763。

## I — Interpretation(自述)

两套互补的工具,解决同一个问题:**读者能不能"看见"和"听出"人物**。

**工具一:烂台词检测(盖名字读对白)**
把对白页上的人名遮住,只读台词。若分不出谁在说话,说明所有角色都在用作者一个人的语气讲话。修法不是"加口头禅",而是给每个人一份语言特征:用词偏好、句子长短、回避什么话题、在什么情况下会改口。作者自己的极端练法是给每个角色规定语言毛病(结巴、乱用词、每句都强调一个词)。

**工具二:示而不讲(Show, don't tell)**
背景信息不能让人物站出来念给观众听。要改成:
- 画面(丈夫走路时眼睛黏在别的女人身上 = 婚姻出问题)
- 道具(墙上那张瘸腿球队合照 = 他的运动员前史)
- 行为(两人互相不看对方 = 刚吵过架)

**配套工具三:瘸腿和眼罩**
次要人物太多、读起来分不清时,给每人一个视觉锚点(一小撮胡子、永远戴的帽子、一条旧围巾)。作者与搭档用"黑 T 恤 + 下巴小胡子"救活了一个功能性角色,经理人一读就记住了。

## A1 — Past Application(书中案例)

- **迈克·契达的当场检测**:作者早期剧本被评"你的人物说话怎么千篇一律",他不服,做了盖名字测试——结果一个人物都分不出来,而且发现"所有人的语气都跟我一样"。这成了他此后二十年的固定动作。
- **《大丑孩》(Big, Ugly Baby)**:作者给每个角色设定语言特征(结巴、乱用词、存在主义移民、总是喊叫的外国夫妇、每句必有一个词加黑体),结果剧本读起来顺畅得多,朗读也更有趣。
- **《十分贱女孩》的男孩角色**:功能重要但读完记不住,改台词无效。最后的解法不是文字,是视觉——黑 T 恤 + 小胡子,同一稿之外只改这一处,读者立刻记住。

## A2 — Future Trigger(触发条件)

**用户情境**
1. 多人对话写得"像一个人在自述"。
2. 需要交代背景,但不想用大段解释。
3. 角色多,读者/观众分不清谁是谁。
4. 文案/脚本里的"人设"只停在形容词上,没落到语言与行为。

**语言信号**
- "台词都差不多 / 分不清谁在说话 / 对话很平"
- "怎么自然地交代背景 / 不想用旁白解释"
- "人物太多记不住 / 配角没记忆点"
- "对白 / dialogue / 人设怎么落地"

**与相邻能力的区分(定稿)**
- 要判断**主角是否成立** → `protagonist-antagonist`。
- 要判断**情绪是否单调** → `escalation-color-wheel`。
- 本卡只管"人物在纸面上是否可辨识、信息是否靠展示传达"。

## E — Execution(可执行步骤)

1. **取样**。取一页/一段包含 3 个以上角色的对白。完成标准:这段里有信息交代或冲突,不是闲聊。
2. **盖名字测试**。遮住人名读一遍,标出"读不出是谁"的行。完成标准:给出可辨识率(能认出的行数/总行数);低于 70% 即需重写。
3. **建语言档案**。为每个角色写三行:爱用什么词 / 句子多长 / 绝不说的话。完成标准:任意两人之间至少有一处明显冲突的设定。
4. **改写测试行**。只改"读不出"的那些行,不改变情节。完成标准:改完后遮名字重测,可辨识率上升。
5. **示而不讲替换**。把稿中所有"人物解释背景"的段落列出来,逐条改写成画面/道具/行为。完成标准:每条都能用一句话描述"观众看到了什么"。
6. **加锚点**。为 3 个以上次要角色各设一个视觉/行为锚点。完成标准:锚点在角色每次出现时都可复用,且不与主要角色重复。
7. **输出**:语言档案表(角色/用词/句长/禁区)+ 可辨识率前后对比 + 示而不讲替换清单(原句→画面)+ 配角锚点表。

## B — Boundary(边界)

- **"示而不讲"是影视/图像媒介的铁律,不适用于所有文本**。合同、说明书、论文必须直说;播客/有声书没有画面,只能靠语言差异。
- **不要给所有角色都加"特色"**:主角与关键配角需要,功能性路人不需要;全员怪腔怪调反而失真。
- **语言特征不是口音模仿**:不要用方言拼写或刻板印象当特征,那会冒犯且难读。
- **"说情节"有合法例外**:角色刻意说谎、试探、或剧情需要他讲给另一个角色听时,"说"本身可以是戏。判断标准是:这段话是否在角色之间产生了效果。

## 相关能力

- **组合** `protagonist-antagonist`:先有人物定型,才有语言档案可建。
- **组合** `escalation-color-wheel`:换色改造常和对白重写同时进行(同一场戏换情绪基调)。
