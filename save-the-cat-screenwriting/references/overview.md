# 《救猫咪》三部曲 — 全书概览

- **作者**:布莱克·斯奈德(Blake Snyder,1957–2009),好莱坞职业编剧,卖出 13 个原创剧本,其中两个百万美元级(《核心家庭》卖给斯皮尔伯格),《龙妈出差》《小鬼富翁》被拍成电影。
- **原书**:Save the Cat! The Last Book on Screenwriting You'll Ever Need(2005)/ Save the Cat! Goes to the Movies(2007)/ Save the Cat! Strikes Back(2009)
- **中译**:浙江大学出版社,2011 / 2011 / 2013

## 一句话

好莱坞卖得掉的好故事 = 一个原始的目标 + 一条由 15 个节拍支撑的转变弧线;而这一切可以在动笔之前用纸笔工具验证和修理。

## 三本书的分工

1. **《电影编剧宝典》** — 方法论主干:故事线四要素、10 种故事类型、主角与坏蛋、BS2 十五节拍表、案板、八条金科玉律、七/九项自检。
2. **《经典电影剧本探秘》** — 案例库:50 部影片逐部拆 15 个节拍,每型再分子类型(如鬼怪屋分家庭怪物/连环杀手/超自然/虚无型),用于验证与对照。
3. **《反击战!》** — 诊断与修稿:烂点子七警示、三病症(枝蔓/半步/模糊)、15→40 扩卡、五要点结局、故事脊柱五问、逻辑警察、绿灯检查清单。

## 骨架(七个一级论点)

1. 一切从"电影讲什么"开始——一句话故事线是全行业的流通货币。
2. 创意必属十种底层引擎之一,先懂类型硬规则才能"似而不同"。
3. 主角与坏蛋是一对镜像;动机越原始,传播半径越大。
4. 结构可量化:15 节拍 + 40 张场景卡,每卡必有情绪翻转与冲突。
5. 八条金科玉律是可判定的禁区,违规必有病理。
6. 剧本会生病,但病有名字、有处方(三病症 / 五问 / 绿灯清单)。
7. 这是门生意:先卖一句话,再卖结构,最后卖自己。

## 关键批判(用于界定适用边界)

- **时代局限**:110 页/110 分钟的规格来自 2005 年前后的好莱坞商业片生态;流媒体、剧集、非西方叙事需重算比例。部分片例与行业判断(剧本大赛、Email 推销)已过时。
- **立场盲点**:明确面向"卖得掉"的买方市场,对作者电影、艺术表达、细分小众市场解释力弱;案例全部来自个人经验与票房成功,存在幸存者偏差。
- **未证假设**:把"原始性=普适性"当作商业成功的充分条件;把 15 节拍的页码位置当作因果规律(实为案例归纳);把"转变弧线"当作故事的必要条件(状态型/散文式作品常不满足)。
- **最强反对意见**:清单化叙事会导向同质化;大量杰作并不经过"先卖故事线"的流程。作者的内置回答是——规则的价值在于"懂了才能破",他面向的是想靠写作谋生的人。

## 怎么用这套能力

- 只有一句话 → `logline-validation`
- 要排整条结构 → `beat-sheet-bs2`,再下到 `board-workflow`
- 不知道写什么类型 → `story-types-10`
- 人物立不住 → `protagonist-antagonist`
- 说不清"到底在讲什么" → `spine-five-questions`
- 结尾平 → `five-point-finale` + `escalation-color-wheel`
- 稿子要交/要评审 → `story-diagnosis-checklist`,先 `three-structural-ailments` 定性
- 设定怕崩 → `logic-cops`
- 说不上哪不对 → `golden-rules`
- 点子还没验证就开始护着 → `bad-idea-warnings`
- 对白糊、配角记不住 → `dialogue-detection`
