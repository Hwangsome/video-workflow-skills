# 决策规则速查 — 救猫咪三部曲(电影编剧宝典 / 经典电影剧本探秘 / 反击战!)

| 能力 | 一句话规则 |
|---|---|
| 故事线四要素验证 | 一句话必须同时有意外、心理影像、观众与成本、有杀伤力的片名,缺一项就回炉,并用陌生人测试实测。 |
| BS2 十五节拍表 | 把整条叙事按 15 个固定功能节拍铺开,每格一句话;催化剂晚于 15%、铺垫超 23% 就是铺垫过载。 |
| 案板工作流(15→40 场景卡) | 四行板、每行 9–10 张卡、总数 36–40;每卡必标情绪翻转(+/-)与冲突(><),标不出的卡就该删。 |
| 10 种故事类型判别 | 创意必属十台引擎之一(鬼怪屋/金羊毛/如愿以偿/麻烦家伙/变迁仪式/伙伴之情/推理侦探/愚者成功/被制度化/超级英雄),先判型再套硬规则。 |
| 主角与坏蛋设计 | 主角 = 最大冲突 + 最远情感 + 最原始目标 + 最不想变却最需变;坏蛋要坏到极致、只稍强一点、并与主角争同一样东西。 |
| 故事脊柱五个问题 | 五问校直主干——谁是主角/难题是什么/怎么开始与结束/实体与精神目标/主题是什么;卡在哪问,病就在哪问。 |
| 五要点结局 | 召集团队→执行计划→高塔意外(计划是陷阱)→深入挖掘→新计划;第三步决定第三幕是不是"打一遍就完了"。 |
| 诊断评审体系(九项快扫 + 绿灯清单) | 先九问快扫定位弱项,再对弱项所在节拍跑深度清单,最后给"可交/改一轮/不建议继续"的放行结论。 |
| 三病症诊断 | 说不清哪里不对时先归病:枝蔓过多(删)、半步缓行(换)、节拍模糊(砸)。 |
| 逻辑警察一致性审查 | 不查是否符合现实,只查是否违反自己立的法则——每部作品自带法规,审查官只执法不立法。 |
| 金科玉律八条禁区 | 八条红线逐条比对:救猫咪、泳池教皇、单一魔力、铺垫上限、黑人兽医、小心冰川、曲线公约、别让媒体介入。 |
| 烂点子七条警示 | 越不敢讲、越怕被偷,越可能是烂点子;七条警示中命中第 5(无逻辑点)或第 6(只有画面没故事)即判硬伤。 |
| 烂台词检测与示而不讲 | 盖住人名读对白,认不出谁在说话就是失败;背景信息改用画面/道具/行为承载,别让人物念给观众听。 |
| 情节加速双律(转折×3 + 情绪色环) | 情节要螺旋加速(每段揭示大于前段),情绪要用满色环(缺哪种颜色就换一个场面的基调)。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
