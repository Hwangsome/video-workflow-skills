# 创意诊断与评审

发散时保护候选的差异，定稿时才精查执行。先指出本稿值得保留的具体画面或台词，再按影响修最关键的问题。用户只要校字就校字，不擅自推翻结构。

## 通用检查

| 问题 | 查哪里 | 不通过时如何改 |
|---|---|---|
| 看什么 | 首屏动作与首句 | 让处境或设定可辨认，而非泛泛“你知道吗” |
| 等什么 | 开场承诺及中段新信息 | 给观看回报，减少重复解释 |
| 记什么 | 最强一幕与商品关联 | 商品成为动作、角色、笑点或视觉符号的一部分 |
| 信什么 | 事实主张及证据 | 缩小结论、补条件或换不依赖该事实的表达 |
| 做什么 | 结尾与本次目标 | 记忆、搜索、收藏或购买，按目标选择，不硬塞促销 |
| 能拍吗 | 动作、时间、资源与连续性 | 保留创意机制，缩减执行规模 |

每个问题用 `通过 / 需改 / 待核实 / 不适用` 并指具体镜号或台词；不因氛围片没有故事而扣分，不用清单总分预测成效。

类型专项：展示看视觉变化与主体辨识；种草看生活细节与体验真实性；口播看观点、人格与可听性；搞怪看设定、升级与回收；剧情看目标、因果与伏笔；氛围看声画编排；系列看稳定识别与新变化。

## 三病症的短视频用法

- 散：多个笑点/卖点互抢，删或拆条；保留能服务主点子的内容。
- 拖：动作和台词重复同一信息，合并并让下一步改变局面；舒缓体验的停留不自动算拖。
- 软：该看见变化的地方只靠旁白宣告，改成选择、动作、对照或信息揭示；不是所有镜头都要戏剧化。

先修目标与创意，再修结构、镜头与台词。问题局部就局部修改，不能机械按缺三项判重拍；若关键效果无法复现，明确是证据或生产问题，改文字解决不了。

## 评论、异议与误解

先分类：实际质量问题、使用限制、缺乏信息、误解、个人偏好。真实问题要如实记录、调整主张与适用对象；不能用更大的笑点或挑战掩盖。信息不足用直答或对应演示；已有错误认知可用更易理解的真实解释，不复述放大耸动说法，也不嘲讽消费者。

## 拆解参考

按时间段记录可见动作、台词、剪辑与商品出现；再单列你推断的注意机制、情绪和转化逻辑。保存来源与访问范围，不可访问的视频不假装看过。提炼规则和可替换槽位，再改变人物/情境/动作/包袱中有意义的部分；只换品牌名不算独立创意。播放量高只说明观察到的结果，不证明某个镜头导致成交。

## 输出改稿意见

`位置 → 观察到的问题 → 影响 → 替代动作/台词 → 保留项 → 优先级`。优先修一到三个最影响目标的问题。报告 `创意草案 / 待核实 / 可拍摄稿`；结构检查、事实核验、朗读、试拍、上线测试分别说明是否实际完成，不把自己推演冒充观众反馈。
