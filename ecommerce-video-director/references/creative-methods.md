# 创意方法：选机制，不拼套路

遵守入口的选择流程：本文件帮助生成具体候选，不赋予模型在方向未定时自行选中并写完的权限。先交带编号创意并解释推荐；用户已选、已指定或授权代选后再展开。只要点子时不强行推进下一阶段。

需要把方向卡展开到脚本时，读 [分类型手册](direction-playbooks.md)；需要比较完整交付颗粒度时，读 [五方向完整练习](worked-example.md)。不要默认加载示例并模仿其中情节。

## 把资料转成创意燃料

从真实资料中摘录：场景细节、重复抱怨、购买前疑问、使用误解、产品结构与操作、售后问题。每项保留来源。没有用户研究时，将“消费者可能…”写成假设，不伪装成评论原话。

建立 `属性 → 在什么条件下改变了什么 → 对谁有用 → 用什么画面证明`。例如已知“可折叠”，可以拍桌面占用的前后变化；不能自动推出“承重强”“永不松动”。

## 机制菜单

先选内容方向，再找具体点子；下列不是互斥分类，也不是固定脚本公式。

## 内容方向矩阵

| 方向 | 观众为什么看 | 创意抓手 | 容易写俗的方式 |
|---|---|---|---|
| 产品展示 | 看外形、细节、操作与变化 | 物件编舞、尺度错位、一镜变形、微距探索、声音节奏 | 转台加参数字幕，没有设计过的视觉事件 |
| 生活种草 | 代入“这就是我的日常”，发现想要的体验 | 一段微小的生活仪式、意料外的使用场景、真实取舍与细节 | 假装买家背卖点，空喊“姐妹闭眼入” |
| 人物口播 | 听一个有态度、会表达的人讲明白或讲好笑 | 鲜明立场、自问自答、吐槽清单、角色独白、边讲边做 | “家人们看过来”后依次念参数 |
| 搞怪离谱 | 看荒诞设定如何继续发展，等笑点兑现 | 一本正经胡说八道、拟人、身份错位、夸张仪式、重复升级、冷幽默 | 无关热梗拼贴、大喊大叫、最后硬插商品 |
| 剧情反转 | 跟人物一起误解、选择，最后重新理解 | 双方目标错位、误会升级、视角揭示、前后呼应 | 产品最后突然出现，人物轮流念广告词 |
| 感官氛围 / ASMR | 享受质感、动作、声音和秩序 | 一连串令人满足的操作、材质对话、节奏与构图 | 没有具体声画设计，只写“高级治愈” |
| 伪纪录 / 采访 | 看一种熟悉的严肃形式讲意外的事 | 产品招聘会、物件访谈、办公室观察、虚构新闻播报 | 伪装真实新闻、专家或消费者背书 |

### 让点子更大胆的发散动作

围绕商品真实属性，选一两种动作试写：让物件拥有职业或欲望；把小需求当成大事件；互换人与商品的身份；改用不常见的叙述者；把一次动作升级三次；用严肃形式讲琐碎事情；把参数变成空间或动作；让结尾重新解释开头。再问“哪一个瞬间值得被记住”，保留最强的一幕。

搞怪可以让世界观、人物反应和情节极度夸张，商品事实仍要准确。明显的拟人和荒诞不需要按真实测评逐镜证明；承重、功效、价格等具体事实仍需来源。特效展示超现实功能时，使演绎性质可辨认，并用真实操作承接购买理由，不让观众误以为商品真有该功能。

资源少时压缩角色、机位和道具，不直接把大胆点子降级成普通口播；一人分饰、画外音、物件视角与纸板布景都能承载荒诞设定。

### 按需参考，不预装同一套情节

本页保留生成方法，完整实例放在 [examples索引](../examples/README.md)，避免每次创作都先看到同一组面试、下班或感情误会。先提出当前商品的候选，再按需查一个实例：家清看尺度揭示，食品看操作声与时间片，服饰看使用状态与观点。多种方向可以共享商品事实，但观看回报要不同。

## 按情境选机制

| 适合的情境 | 可尝试的机制 | 不合适时的信号 |
|---|---|---|
| 好处可立即看见 | 先呈现结果，再倒回关键动作 | 结果依赖长期使用或无法复现 |
| 用户有常见误解 | 给一个事实，修正预期，再解释机制 | 只能靠夸张说法制造反常识 |
| 用户在两个方案间犹豫 | 同条件、同任务的对照 | 条件不同，或刻意让旧方案失败 |
| 用户说“我不需要” | 具体生活小冲突，把隐性成本变可见 | 人为放大焦虑、把所有人写成痛点人群 |
| 品类同质化 | 换使用者视角、空间或时间约束 | 仅换角色服装，购买理由不变 |
| 有强触觉、声音或操作体验 | 操作过程、细节声与微小结果 | 特效或拟音被包装成真实效果 |
| 用户担心某个缺点 | 诚实说出限制，再展示适合条件 | 以“自曝缺点”掩盖重要使用限制 |
| 需要剧情与品牌记忆 | 人物目标碰到阻碍，产品改变行动路径 | 产品只在结尾贴片，拿掉不影响剧情 |

没有一种机制必然优于其他机制。选择由本次目标、证据和制作资源决定。

## 发散与筛选分两轮

先从不同起点各找候选：一条真实属性、一处生活矛盾、一个有辨识度的动作、一种人物态度、一种类型惯例。用换视角、反向目的、认真处理荒诞事等动作改写。不要在第一轮就要求每个点子补满转化与证明，这会把候选压回同一广告模板。

第二轮为候选找商品关联与执行方式，比较“新鲜在哪里、为什么会继续看、能否记住商品、事实是否成立、能否用资源拍出”。优先保留彼此有区别的方向，不因某条更稳就把其余全部改成它。没有新意时，把最常见的开场和结尾列为本轮禁用，再从不同叙述者或动作重新发散；这只是本轮破局，不是长期禁词。

创意量不等于创意质。批量任务先定义互不重复的方向/机制组合，再填每条，发现重复时替换核心设定，而非再添一批形容词。类比可以帮助构思，如“桌面像公司”，同时检查失效处：物件的虚构欲望不能被解释成产品具备智能。

### 防止“例子换商品名”

对每条用四个短语标记：`矛盾或观点 / 叙述者 / 核心动作 / 回收方式`。同一批候选若这些相同，只剩人名、商品或场景名不同，合并或改造；同一类型也应能有不同机制。

从新商品重新找入口：粘毛器可用微距发现与逐格揭示；挂耳咖啡可用展开、挂杯、冲泡的声画与等待；双向拉链服饰可用站坐时的操作选择。这里给的是属性到机制的关系，不是让后续作品固定照拍。是否真有该结构仍以实际资料为准。

看到“会议、面试、辞职、求婚误会”时，问它是否由这个商品的特定属性生长出来，还是模型熟悉的省事套路。后者先尝试换观看动机或关键动作，而非直接禁用所有这类创意。不要为了新颖添加不存在的功能。

## 创意卡

每卡用短段落填写：
- 方向、名称与一句话点子：看什么，设定哪里新鲜；有故事时再写人物目标与变化。
- 洞察及状态：真实来源 / 待验证假设。
- 第一画面与第一句话：为什么与目标观众有关。
- 3—5 个关键动作或情节，以及最值得记住的一幕；不能只交抽象类型名称。
- 创意机制：预期如何被改变；后面如何兑现。
- 产品角色与证明：具体哪项机制让结果成立；证据来源。
- 结尾动作、制作资源、主要风险、待验证问题。

推荐时说明取舍，如“更贴近租房收纳场景且只需一位演员；视觉反转较弱，可用物品占位对照补足”。不以主观评分装作测试结果。

## 剧情模式

用最短的因果链：`人物想做成一件事 → 具体阻碍 → 尝试受挫或选择 → 产品使新行动成立 → 可见结果 / 反转`。时长短时合并节点，人物不必经历宏大的成长。

让人物说他在当下会说的话。遮住角色名仍应能分辨关注点；别让所有人轮流背广告词。用行为、道具、空间关系交代背景。反转可以改变理解，但不得把虚构故事宣称为真实消费者经历。

## 改稿诊断

| 症状 | 先检查 | 可操作修改 |
|---|---|---|
| 抓眼但记不住商品 | 钩子与产品是否有因果关系 | 用产品动作兑现开头问题 |
| 像说明书 | 有无具体任务与代价 | 用一个使用场景组织参数 |
| 有趣但没购买理由 | 结果是否与观众选择有关 | 把结果落到实际使用差异 |
| 每条都一个套路 | 是否只改台词 | 改冲突、视角或证据形式 |
| 不可信 | 主张是否超出证据 | 缩小结论，补条件或换展示方式 |
| 拍不出来 | 演员、场地、特效是否超预算 | 保留机制，简化动作与场景 |
