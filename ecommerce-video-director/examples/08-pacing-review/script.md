## 01 一句话故事与核心承诺

- 故事：午间，一个准备继续刷手机的人选择先展开挂耳泡一杯咖啡，最后把手机扣下，给自己留一段空隙。
- 核心承诺：看清小包展开挂杯的形式，并看到人物把这一刻留给自己的选择；不承诺健康或提神效果。

## 03 叙事与情绪节奏
| 段落 | 叙事功能/信息转折 | 情绪与触发 |
|---|---|---|
| S1 | 钩子：提示音带来下一件事，手却选择小包。 | 被提示音拉住→主动选择；转向小包的手触发变化，不额外停手等台词。 |
| S2 | 推进：小包装是什么、如何展开得到回答。 | 犹豫→专注；连续的手部操作转移注意。 |
| S3 | 信息揭示：给品类名称，让挂杯机制可理解。 | 专注→确认；挂稳后动作放缓。 |
| S4 | 观看回报：展开之后的冲泡动作和声音，不额外引入支线。 | 确认→等待；滴落声维持安静节奏。 |
| S5 | 结尾兑现：用扣手机的行动回答开头，留下商品形式与查看动作。 | 等待→主动放松；变化来自人物选择，非商品功效。 |

### 内容段不是单镜头
以下为段内内容推进的编排估计，不是实测用时或最终分镜。

### S1 · 段内节奏
| 段内秒数（估计） | 可感知变化 |
|---|---|
| 0 | 桌上手机亮起，手开始伸向它。 |
| 0.8 | 手改变方向，转向杯旁小包。 |
| 1.8 | 拿起包装，接续下一段拆包。 |

- 停留理由：只保留可读的选择过程，拿到小包即进入拆包，不为旁白额外摆停。
- 衔接建议：从动作中进入；拿包到拆包连续衔接，具体切点留给分镜。

### S2 · 段内节奏
| 段内秒数（估计） | 可感知变化 |
|---|---|
| 0 | 承接手持包装，开始按说明拆包。 |
| 1.8 | 取出并准备滤袋，实际步骤待样品核对。 |
| 3.8 | 展开纸挂耳，形成可挂杯结构。 |

- 停留理由：6秒暂留给必要操作与看清结构；不是强制长镜头，不能为快剪省掉关键用法。
- 衔接建议：删去取包和反复摆正；展开后接挂杯。实际步骤较长则重排窗口，不能加速伪造便捷。

### S3 · 段内节奏
| 段内秒数（估计） | 可感知变化 |
|---|---|
| 0 | 将已展开挂耳放上杯口。 |
| 1.6 | 确认实际支撑关系，观众能看清挂杯形式。 |
| 2.8 | 手开始拿壶，衔接下一段注水。 |

- 停留理由：给挂杯结构被看清的时间；确认完成即推进，无额外端着展示。
- 衔接建议：动作结果直接引出注水，保留真实支撑关系，不规定必须切几个镜头。

### S4 · 段内节奏
| 段内秒数（估计） | 可感知变化 |
|---|---|
| 0 | 水壶已就位，按说明开始注水。 |
| 1.8 | 画面持续呈现实际水流与滤袋变化，字幕提示过程节选。 |
| 3.3 | 呈现真实滴落和声音变化；具体发生时刻须实物确认。 |

- 停留理由：用真实水流、滴落和原声提供持续变化，不是静止产品摆放；没有可辨变化则再压缩。
- 衔接建议：保留注水声与滴落的联系；段尾明确省略后续等待，下一段为完成后的另一时间点，不宣称5秒冲完。

### S5 · 段内节奏
| 段内秒数（估计） | 可感知变化 |
|---|---|
| 0 | 进入冲泡完成后的时间点，扣手机，旁白开始。 |
| 1.3 | 拿杯，旁白继续；不额外端杯看镜头。 |
| 4 | 旁白结束后显示“查看冲泡说明”，文字读完即结束。 |

- 停留理由：预留约末2秒读6字CTA，不叠加商品总结；若真人旁白超过前4秒则减字或调整总长，不强行赶读。
- 衔接建议：用已完成的一杯承接明示省略；保留扣手机的回收，字幕与旁白错开，结尾无无目的端杯定格。

## 05 制作交接说明
### 必须保留

- S1手转向小包与S5扣手机的前后因果；主稿结尾不能换成继续刷屏。
- S2展开、S3挂杯的可观察步骤；S4保留“冲泡过程节选”。
- 所有商品动作遵循真实说明；不能把情绪变化写成健康功效。
- 旁白与人物任务并行，不因等台词停手；S5旁白后只留CTA，不新增端杯盯镜头。
### 可以调整

- 人物服装、桌面颜色、包装摆放可调整，保持人物和杯的连续关系。
- 提示音可替换为实际可用的原创提示声；无权使用的手机界面改成自制通知。
### 必要道具

- 实际挂耳产品及包装、适配杯、水壶和按说明可用的水。
- 手机、可安全进行操作的桌面。
### 事实待核实项

- 本例为合成演练；真实SKU、杯型、水温、水量、步骤及注意事项须由上游替换核实。
- 真人旁白试读、拆包挂杯和注水过程均未实际计时。
- 出镜人物、场地和实际画面授权未落实，详见上游素材风险清单。
- v2的24秒建议须经试读与样品计时确认；若真实任务锁定30秒，另行重排内容，不将此例当固定时长模板。
### 简化拍法

- 保留手与桌面，不出现人物面部；用同一人的手执行转向小包、拆包、挂杯、扣手机，旁白不变。
- 不能省掉挂杯机制或过程节选提示；不新增具体景别、焦段或运镜要求。
