## 01 内容策划 / 编导

### 项目与受众定位

- 商品：独立包装挂耳咖啡；演练给定结构为可展开纸挂耳，挂在适配杯口后按说明注水。无产地、成分、风味、咖啡因、提神或价格资料。
- 对象与处境：午间有适配杯和热水、习惯拿手机填满空隙的人。此为本方案的受众假设，不宣称由用户研究证实。
- 内容目标：让观众记住挂耳挂杯冲泡的形式，愿意查看款式与冲泡说明。暂按竖屏信息流30秒、单人桌面场景构思，非平台已核验规格。

### 选题、核心卖点与创意

- 选题：把冲泡这一杯的过程留给自己，不急着继续刷手机。
- 核心商品表达：小包展开挂耳，在适配杯上冲泡；由结构与操作承载，不能改写成“零设备、随时随地、比其他咖啡更健康”。
- 创意：生活种草为主，操作声音为辅助。人物先要点开手机，接着亲手展开、挂杯、注水，最后把手机扣下。没有额外剧情支线，商品过程就是情绪推进。
- 故事梗概：提示音拉住注意→手选择先泡咖啡→真实结构操作→等待片刻→拿杯，把下一件事留到之后。结尾商品与包装同框。

### 为什么点开、看完、转发

- 点开：首句“这几分钟，我不想再安排一件事”，对应被碎片任务填满的处境，而非承诺神奇功效。
- 看完：展开、挂杯、水流、滴落提供连续声画回报；人是否继续划手机形成轻微悬念，结尾用扣下手机兑现。
- 传播：可让有类似午间习惯的人发给同事表达“先歇一会儿”；这是可能的社交表达，不作为必转发承诺。此片优先商品理解与考虑，转发为次目标。

## 03 编剧 / 文案

### 故事与情绪走向

从“又要用手机填满空隙”，经“专心做一件小事”，到“允许这一刻不再加事”。情绪由被催促到主动选择，转折由手扣下手机触发，不归因为咖啡的健康功效。商品记忆是纸挂耳的展开与挂杯过程。

### 完整脚本

| 段号/时间 | 画面与内容动作 | 角色完整台词 | 旁白 | 字幕 | 必要声音/停顿 | 信息与情绪转折 |
|---|---|---|---|---|---|---|
| 1 / 0—5秒 | 人坐到桌边，手机提示亮起；手指停在屏幕前，小包装放在杯边 | 无 | 这几分钟，我不想再安排一件事。 | 这几分钟，先留给一杯。 | 一声提示后安静，末尾留半拍 | 从被信息拉住，转向自己的选择 |
| 2 / 5—11秒 | 手放下手机，按实际说明拆包、展开纸挂耳 | 无 | 无 | 无 | 包装与纸张声 | 小包装变成可挂杯结构，观众获得信息 |
| 3 / 11—16秒 | 将挂耳放在适配杯口，手确认位置，再拿起水壶 | 无 | 无 | 挂耳咖啡 | 挂杯动作后稍停 | 明确品类、让动作可读 |
| 4 / 16—23秒 | 按包装用法注水，看到真实水流与滴落；不把完整等待硬塞成7秒 | 无 | 无 | 冲泡过程节选 | 原声，保留滴落节奏 | 从操作进入等待，声音提供继续看下去的回报 |
| 5 / 23—30秒 | 冲泡完成后的另一个时间点，按说明处理滤袋；人物把手机扣下，拿杯，包装同框 | 无 | 先把这一杯喝好，别的，等会儿。 | 小包展开，挂杯冲泡。查看款式与冲泡说明。 | 扣手机声，末2秒留商品文字 | 回收开头；落商品记忆与查看动作 |

### 文案确认

- 全部角色台词为无；旁白仅首尾两句，字幕与关键操作一一对应。30秒为影片编排目标，未实际朗读或试泡计时。
- 必须保留“冲泡过程节选”，不能用加速或剪辑宣称30秒完成一杯。实际操作超出段落时间时，调整节奏或明示时间省略，不漏必要步骤。
- 不加入提神、低糖、咖啡因数值、具体风味、优惠或健康主张。真实包装要求的用法与注意事项，由核查后结合实际内容决定是否进入画面。
